# 《临安春信》闲暇情感、节日仪式与顾行舟隐线补充稿 v1

> 状态：`FOUNDATION-DRAFT`
>
> 本稿承接 `story/00-series-outline.md`、`story/01-causal-mystery-and-pacing-revision-v2.md` 与 `story/02-action-choreography-and-comrade-arc-v1.md`。核心新增是 S1-E19 中段“今日无事，勾栏听曲”情感段：它提供轻松呼吸，也让舞台上的安抚话术变成下一集的粮路线索，并把顾行舟的隐瞒直接变成男女主的关系冲突。
>
> 顾行舟的“靠山”不是无条件替他办事的神秘组织，而是由旧同袍、旧脚夫、城门军士、文书和水路伙伴组成的有限人情网络。它能提供入口、记忆或一张纸，不能替他调兵、改令或抹掉旧债。勾栏、听曲、席间规矩和节日仪式的具体细节，是沿用现有 LOC-005/LOC-006 的戏剧化解释；正式历史考据仍由后续生产审阅确认。

## 1. 这段戏要改变什么

### 1.1 外部剧情

E19 的“繁华恢复”不能只作为背景。勾栏里被加钱反复唱出的“今日无事”与“新粮入城”绑定，说明市面上的安心感可能经过安排，但目前只能得到“组织化安抚”的疑报，不能直接定性为阴谋。这个疑报在 E20 进入北来流民登记处，形成“粮进了城，为什么仍有人吃不上”的下一问。

### 1.2 男女主关系

顾行舟想给沈蘅一晚普通生活，沈蘅也确实想暂时不做春信的解释者；但顾把自己已经察觉的风险留在心里，导致“休息”变成单方面安排。两人不因一次听曲立刻和好，而是在散场前形成一条可执行的新边界：

> 可以选择今晚不查，但不能在对方不知情时替对方决定“今晚无事”。

### 1.3 轻松与冲突的比例

- 轻松来自并肩走夜市、误被当作夫妻、分享一包酸橘子、顾行舟坐席仍在看门和沈蘅故意把他拉回台前。
- 冲突来自“他想被当成掌柜，她却看见他仍是押运人”；“她想留下记录，他却想保住一晚不被调查吞掉”。
- 甜味不能抹掉信任损耗。散场时二人仍愿意同行，但已经不能继续假装彼此没有隐瞒。

## 2. 顾行舟的隐秘背景与有限靠山

### 2.1 对外说法与真实内情

| 层面 | 顾行舟对外的说法 | 他不愿主动说的事实 | 戏剧作用 |
|---|---|---|---|
| 身份 | 做过护送和短途镖运 | 曾在边军粮药护送队任押运伍长，退役并非体面离营 | 解释他为什么熟悉军伍顺序，却厌恶被人称“英雄” |
| 旧事 | 石桥冬运只是一次运粮失误 | 他回身救人导致粮车翻覆，曹肃留守桥头，高问删去回身时刻，梁成武从冰水里拖过他 | 让“救人”与“造成损失”同时成立 |
| 靠山 | 酒肆客人消息多 | 旧同袍和旧脚夫仍愿意给他一次问路、一次验货或一张抄件，但每次都会留下人情债 | 让他有入口，却不能替主线开挂 |
| 退役 | 旧伤、厌倦军伍 | 他担心别人知道自己曾参与过后来被封锁、误传和删报的执行链 | 解释他为什么宁可自己挡，也不肯把旧人牵回火里 |

### 2.2 隐线网络的功能边界

| 人物/关系 | 能提供的东西 | 不能提供的东西 | 顾行舟的代价 |
|---|---|---|---|
| 曹肃｜旧同袍、城门军令执行者 | 验门时刻、正式令文、已发生的放行或拒行事实 | 不能无令开城，不能替顾洗掉石桥冬运的责任 | 顾的身份更接近正式记录 |
| 高问｜旧军需文书、城务司执行吏 | 摘要删改的痕迹、签押顺序、谁在何时看过哪一页 | 不能伪造原件，不能把例外变成常规 | 顾必须承认自己也曾依赖文书的“方便” |
| 梁成武｜年长旧兵、现城门军士 | 身体站位、押运习惯、普通军士看到的现场记忆 | 不能替顾出头，也不替他隐藏身份 | 顾面对一个记得他失误的普通人 |
| 裴九娘｜民间水路伙伴 | 吃水、缆绳、船期和货物实际去向 | 不是军伍靠山，不能替顾接管水路 | 顾必须接受非军籍伙伴纠正自己 |
| 旧脚夫/船工 | 谁在何处搬过货、哪辆车真的进过仓 | 不保证消息真实，也不会无偿冒险 | 顾欠下工钱、护送或安全承诺 |

### 2.3 为什么他不对外言说

1. 他说出边军旧身份，就会让别人把酒肆里的每一句判断都当成军令或密报。
2. 他若调用旧人，旧人会被重新问责；尤其是石桥冬运的“回身救人”和“粮车翻覆”不能被一句“我当时是对的”覆盖。
3. 他害怕沈蘅知道后，会把自己当成一条带着旧案的线索，而不是一个可以一起过日子的人。
4. 他也害怕自己一旦承认有人可用，就会再次把人情网络变成替自己承担风险的工具。

E10 先露半卷旧案，E12 露出旧军令痕迹，E19 只露“仍有人替他递一次纸”，E23 才把删节责任说清，E30 让曹肃、梁成武把他写进当下记录，E34 才公开完整身份。每一层都只提供当时人物能够证明的部分。

### 2.4 一笔不能公开的旧债

> 本节是故事层解释，暂不覆盖锁定的 Character Foundation；正式回写前需先处理既有“边地护送与军伍协同行动”表述与本节服役时间的连续性。

顾行舟不愿说的不是“我认识几个人”，而是他离开边军时，曾有人用自己的旧功劳替他保住了转役资格，却没有替他抹掉石桥冬运的粮车损失。

1. 他最初不是将门子弟，也没有显赫姓氏；他靠识路、识水和能在混乱里点清人数，从随队脚夫做到押运伍长。
2. 石桥冬运后，旧军需官只替他争到一份可以回民间谋生的退役文书，没有替他把“回身救人、粮车翻覆、延误半时辰”改成战功。顾行舟因此欠下的是一条活路，不是一份清白。
3. 那份退役文书的副页缺了一枚完整签押；顾行舟若以旧军籍公开求助，就可能把当年替他担责的人重新拉回审问链。他宁可做酒肆掌柜，也不肯拿这份文书向外人证明自己有背景。
4. 他仍能动用旧人情，但每次只问一件小事：一辆车是否过门、一页摘要何时被看过、一个脚夫记得哪段路。对方不替他作证到底，也不替他承担第二次风险。

### 2.5 不显山漏水的表现规则

- 旧同袍来酒肆时，他按普通客人收钱；真正的交情藏在少收一壶热水、把某个座位留到散场，或把一笔旧账记在酒坛背面。
- 他不会当众叫曹肃、高问、梁成武的旧称，也不在沈蘅面前炫耀自己能“通到城门”。只有门闩、纸角、捆绳和站位偶尔暴露训练来源。
- 他向旧人求助前，先准备好回报：护送一段家属、替船工修一处缆桩、把欠下的酒钱补齐，或承担对方被问话的可能。
- 任何靠山只提供局部事实，不提供主线答案；顾行舟若想把小事实拼成判断，必须把来源和未知一并交给沈蘅。

### 2.6 中秋重逢节点｜BACK-E23-01《酒账上的伍长》

- **地点**：LOC-009 停云酒肆，中秋家宴前，楼下只留一张靠墙的客桌。
- **参与者**：顾行舟、沈蘅、一名退役军需旧识的徒弟兼旧脚夫（不命名，待后续 Character Gate 决定）、零散酒客。
- **进入状态**：沈蘅正整理沈怀川手稿的“事实／推断／未证”；顾行舟在备桂花酒，想让这晚只属于家宴和旧稿，不想再出现军伍旧人。
- **旧识目标**：把一条当年未归档的时间记号交还顾行舟，同时不让自己的姓名进入旧案。
- **顾行舟目标**：让来人以普通酒客身份离开，不让沈蘅看到自己仍有一条可用的后门。
- **沈蘅目标**：确认顾行舟为何对一个普通酒客过度谨慎，并决定这条人情是否与沈怀川旧案相关。
- **可演动作**：
  1. 来人进门先喊了一声“伍长”，立刻改口“掌柜”；顾行舟把酒盏放稳，按原价收钱，没有相认。
  2. 来人把一张折过三次的纸压在酒坛底，纸上只有“石桥冬运／回身时刻／未入正册”三个标记，没有姓名。
  3. 顾行舟等对方喝完才收纸；沈蘅没有抢看，只把自己的手稿移到桌边，给他留出主动交出的空间。
  4. 顾行舟说来人只是“替旧账送个回声”，沈蘅问：“那你为什么像在送一个人出城？”
  5. 顾行舟打开纸，发现它不是完整证据，只是旧军需官留下的副记；那位替他争退役文书的人已经不在，留下的只有一处缺签。
  6. 沈蘅没有追问来人的姓名，要求顾行舟把“有人替你保过一条路”和“这条路欠了谁”分别写进两栏。
  7. 顾行舟第一次在她面前承认：“我不是没有靠山，我是不敢把他们叫出来。”
- **转折**：沈蘅发现顾行舟真正隐藏的不是权力，而是旧人曾为他承担过的风险；她对他的怨从“你什么都不说”变成“你把别人的牺牲也替他们藏起来”。
- **选择与代价**：顾行舟把副记交给沈蘅，却保留来人姓名和地址；沈蘅接受隐私边界，但不再接受顾用“普通生活”推迟告知。
- **退出状态**：中秋家宴仍然继续，旧账没有被团圆抹平；E24 的桂夜别席多了一条可追问的背景，E30 的曹肃对峙也不再是突然出现的旧识。

## 3. S1-E19“今日无事，勾栏听曲”五场连续段

> 建议位置：E19 中段，白露、桂花与秋市重新热闹之后；建议占 5 个微短章功能位，最终 `scene_id`、`dialogue_id` 与 `microchapter_id` 仍由 Episode Gate 绑定。

### GOU-E19-01｜停云关门：请一晚普通

- **地点**：LOC-009 停云酒肆，晚饭后，街上的灯刚亮。
- **参与者**：顾行舟、沈蘅。
- **进入状态**：E18 五信已经分裂；城里暂时没有立刻爆发的新事，顾行舟手边却压着一张尚未核实的“新粮入城”回单。
- **顾行舟目标**：让沈蘅接受一次不服务主线的邀约，证明自己可以只做酒肆掌柜。
- **沈蘅目标**：确认“今日无事”是现实状态，还是顾行舟替她删掉了风险。
- **阻力**：顾行舟把回单压在酒肆账本下，沈蘅带着记录簿而来；两个人对“暂时不查”的边界没有说清。
- **可演动作**：
  1. 顾行舟收下门板，检查门闩后又把手收回，刻意不再看后门。
  2. 他从柜底取出两张春台入场牌，位置一张靠里、一张靠门；沈蘅一眼看出靠门的位置是他习惯的退路位。
  3. 顾把她的记录簿推回她手边，没有抢走，只说：“今日无事，勾栏听曲。”
  4. 沈蘅摸到账本下露出的纸角；顾按住账本，却在她看向自己时松手。
  5. 她提出条件：若有眼前的危险，他必须先说；今晚不查，不等于她同意最后一个知道。
  6. 顾答应“今晚不带案子”，没有说明自己已经看见回单上的异常时刻。
- **对白意图**：顾是邀请，也是试探；沈蘅接受的是同行，不接受被安排无知。
- **转折**：顾说“城里今晚没有要紧事”，沈蘅追问“没有要紧事，还是你不打算把它叫要紧事？”他没有立刻回答。
- **选择与代价**：沈蘅仍然收起记录簿，给他一次普通邀约的机会；顾得到同行，却把第一笔隐瞒带进了这段关系。
- **退出状态**：两人都以为可以短暂放下调查，但“无事”已经变成一条需要证明的关系承诺。

### GOU-E19-02｜御街夜市：酸橘子不动声色

- **地点**：LOC-005 御街夜市，春台入场前的桂花摊与听曲排队处。
- **参与者**：顾行舟、沈蘅、橘子摊贩、售票小吏、排队听客。
- **进入状态**：两人已经约定第一支曲唱完前不谈案子；顾仍在替她挑避开油水的路，沈蘅故意不顺着他的路线走。
- **目标**：让两个人有不靠解释的亲近；让顾行舟的职业习惯在轻松场里显出可爱，也显出控制欲。
- **可演动作**：
  1. 摊贩递来一小包盐渍酸橘。沈蘅先咬下一瓣，酸意上来，脸上只停了一瞬。
  2. 顾没有问“酸不酸”，只是把自己纸包里那瓣裹糖的橘肉推到她手边，顺手把她面前那瓣拿走。
  3. 沈蘅看见了，没有道谢，只把糖橘掰成两半，留一半在他碗边；顾仍低头吃那瓣酸的。
  4. 他走到队伍外侧，背靠能看见两条巷口的位置；沈蘅把他的袖口往里拽：“今日听曲，门不必替你坐。”
  5. 售票小吏问“二位同席还是分席”，顾一板一眼报出“两张入场牌”；沈蘅接道：“他只会数人，不会数心。”排队的人笑，顾不知该回什么，只把剩下的酸橘纸包收好。
  6. 夜市摊贩对另一桌说“新粮进城，今日无事”，同一句话第一次离开舞台出现在他们耳边。沈蘅下意识摸记录簿，顾看见后没有阻止，只说“先记时辰，别急着下结论”。
- **幽默/关系字段**：`HUM-E19-GOU-01`；错位＋物件笑点；顾用位置表达照料，沈蘅用挪袖表达反控制；笑点之后两人共同记下“夜市、入场前、同一句话”。
- **选择与代价**：顾第一次没有替她收走记录动作；沈蘅第一次把亲近动作和核验动作放在同一张纸上。
- **退出状态**：酸橘子形成两人之间不说破的分享物；“今日无事”出现第二个来源，轻松约定开始被线索侵入。

### GOU-E19-03｜勾栏听曲：一支曲里的三次安抚

- **地点**：LOC-006 春台瓦舍（勾栏），前台席面、台口与侧台之间。
- **参与者**：顾行舟、沈蘅、柳十四、乐工、茶博士、付赏钱的粮行席客及普通听客。
- **进入状态**：顾坐在靠门一侧，沈蘅把他换到内侧；柳十四准备唱一支桂花小曲，顾念娘要求她不要临时改词。
- **三方目标**：
  - 顾行舟想把一支曲听完，不让沈蘅把所有生活都转成证词。
  - 沈蘅想听曲，但也想知道台上的词是不是自然流行。
  - 柳十四想把舞台留给自己的演唱，不替粮行席客把未核事实唱成定论。
- **动作节拍**：
  1. 报曲名、打板、奉茶和收赏钱按正常顺序进行；这一套入场仪式先让两人落回普通听客的位置。
  2. 柳十四唱到副段时，茶博士从一处包厢收来加赏牌，牌上没有完整姓名，只写“新粮既入，安众心”与一处入仓时刻。
  3. 乐工按牌上的要求把“今夜无忧，今日无事”接进副段；台下、茶席和夜市的同一句话开始互相回声。
  4. 沈蘅在记录簿上写下“台上／茶席／夜市，时辰相近”；顾将酒盏移到簿子上，随即意识到自己又在挡她，便把酒盏移开。
  5. 柳十四第一遍照唱加词，第二遍在“无忧”处停半拍，只唱完原曲的尾音；台下听客替她把“今日无事”喊出来。
  6. 顾认出加赏牌上的结绳方式与旧军粮队捆报纸的手法相似，但不确定是旧人、仿制，还是巧合。
  7. 沈蘅问他“你听出什么了”，顾只答“先听完”，却已经把注意力从曲子移到了侧台。
- **曲词边界**：加唱句只作为舞台内的安抚话术，不作为全城事实；柳十四的停半拍是小幅职业反应，不取代 E22“以柳望舒署名新曲”的公开选择。
- **转折**：茶博士低声告诉柳十四，同一时刻已有三个席位加赏同样一句；沈蘅听见，顾也听见，但顾先看向后门。
- **选择与代价**：顾选择离席核对，失去与沈蘅一起听完整支曲的普通愿望；沈蘅选择跟上，失去“今晚不查”的表面约定。
- **退出状态**：舞台不再只是情感背景；“今日无事”成为可记录的传播动作，柳十四保住一丝改词空间，男女主进入必须说清楚的后廊。

### GOU-E19-04｜春台后廊：你给我入场券，不给我知情权

- **地点**：LOC-006 后台侧廊，戏箱、帘幕、茶水间与后门之间。
- **参与者**：顾行舟、沈蘅、柳十四、茶博士、顾念娘的后台管事。
- **进入状态**：顾要追问加赏牌来源；沈蘅跟来；柳十四不愿自己的舞台成为两人争执的后门。
- **顾行舟目标**：确认加赏牌是否牵涉旧军粮路，同时不让旧人和沈蘅被卷进来。
- **沈蘅目标**：得到顾已经知道的部分，自己决定是否继续查。
- **柳十四目标**：保护春台的生计与艺人边界，不替任何一方证明整条粮路。
- **动作节拍**：
  1. 顾先把后门的门栓放回半落位置，给茶博士和沈蘅留出退路，但没有把人关在里面。
  2. 沈蘅把加赏牌放在戏箱盖上，要求柳十四说自己亲眼看见的部分；柳十四只确认“谁递牌、何时递、要求加哪一句”。
  3. 顾说明自己认出的是捆报纸的旧手法，不是下令者；他还知道一两个旧脚夫能问到入仓时刻，但那会暴露他的旧身份。
  4. 沈蘅问：“你带我来听曲，是想让我休息，还是想把有事的地方替我关在门外？”
  5. 顾回答：“我想让你有一晚不必跟着我害怕。”沈蘅把加赏牌推回他面前：“你把害怕留给我猜了。”
  6. 后台管事催柳十四上台，柳把牌撕成两半：一半留下时间和曲句，一半退给来客，避免完整席号落入外人手中。
  7. 顾没有抢牌，也没有替柳做决定；他把自己确认的内容写在纸背，分成“亲见”和“未证”两栏交给沈蘅。
- **核心对白意图**：顾从辩解转为承认；沈蘅从逼问转为要求共同承担判断；柳十四用撕牌保护自己的舞台，不做男女主的传声筒。
- **转折**：纸背的入仓时刻与 E19 新粮进城的公开时刻相连，证明加唱不是随口讨彩；但没有足够证据证明粮行操纵全部流言。
- **选择与代价**：顾第一次在关系冲突里主动交出“自己知道但还不能证明”的部分；沈蘅接受暂不公开完整席号，代价是她承认隐私与核验不能同时一次满足。
- **退出状态**：信任下降，诚实上升；顾的隐线有了入口，沈蘅不再允许“普通生活”成为不告知的借口；E20 的粮路核对获得一个可复核起点。

### GOU-E19-05｜散场：把甜的留给你，不能把事藏起来

- **地点**：LOC-005 夜市外沿至 LOC-009 停云酒肆回路。
- **参与者**：顾行舟、沈蘅，散场听客、收摊摊贩。
- **进入状态**：曲已散，柳十四没有完整重复安抚句；听客却把“今日无事”带出勾栏，秋市仍显得安稳。
- **动作节拍**：
  1. 顾把剩下的糖橘递给沈蘅，仍不解释；沈蘅接过后掰下一半放回他掌心，结束两人之间的无声交换。
  2. 他提出送她回香铺，她没有拒绝同行，却把路线交给自己选择，顾只在后一步跟着。
  3. 她在桥边停下，把两栏记录分给他一栏：“你写亲见，我写听见；明日各自去问，不替对方先下结论。”
  4. 顾补上自己知道的“旧捆法”，并写明“不能证明是旧人”，在纸下署名。
  5. 沈蘅问“下次还能听曲吗？”顾想答“今日无事”，停了一下，改说：“下次先说各自带了什么事。”
- **情感落点**：两人没有牵手或马上和解；他们并肩回城，距离比来时稍远，但第一次拥有共同写下的规则。
- **片尾因果**：第二天 E20 的北来流民登记处出现同样的“今日无事/新粮已入”说法，登记内容却显示粮食没有按需要分配；顾若要调用旧脚夫或城门线索，必须先告诉沈蘅。

## 6. 节日仪式与人物弧线的绑定

### 沈蘅

- 从惊蛰开铺时把“异常”留在家里，到上元旧案中把纪念和事实分开，再到中秋愿意与家人分食却不替父亲翻案。
- 她在 E19 允许自己听曲、吃酸橘、被照顾，但不接受“被照顾所以少知道”。这让她的爱情选择与她建立春信屋的制度原则一致。

### 顾行舟

- 上元对他不是热闹，而是封桥、护粮、旧同袍和没有写完的责任。
- 他在 E19 试着只做带人听曲的掌柜，却在台上认出旧军伍捆法；他的成长不是不再警觉，而是警觉后把已知、未证和选择权交出来。
- 酸橘子的小动作保留他的照料本能，但散场的“亲见/未证”让照料不再等于替对方删风险。

### 柳十四／柳望舒

- 她把舞台仪式从“报曲—唱词—收赏”逐步改成“报来源—唱可证—允许更正”。
- E19 的停半拍只留下可感知的职业抵抗；E22 才完成公开署名与指定曲冲突，避免人物弧线一次用尽。

### 曹肃、高问、梁成武

- 节日和门禁使三人的旧位置具体化：曹肃负责门是否能开，高问负责命令如何被写，梁成武负责普通执行者的身体站位。
- 他们不是顾行舟的“后台团队”，而是在上元旧伤和冬至封门中各自留下名字、时刻和责任的人。

## 7. 生产交付边界

正式逐场化时，每个轻松/仪式场都要补齐：

`objective / obstacle / entry_state / tactic / turn / choice / changed_state / causes_next / subtext / relationship_delta / continuity_refs / ritual_action`

并确认：

- 勾栏听曲的轻松感来自人物行为、食物、礼数和误会，不来自现代网络词或脱离时代的玩笑；
- 酸橘子、入场牌、加赏牌、曲词停半拍、亲见/未证两栏和回程路线都能在后续连续性中被找到；
- 顾行舟的旧人脉每次使用都有现实代价，不能让“靠山”替他解决主线；
- 节日仪式必须改变证据、秩序、关系或劳动，不能只做装饰性蒙太奇；
- 不写镜头、镜位、剪辑或生成提示，把舞台调度和观看重点交给 Director 与 Episode Gate。

## 8. 有趣小场景补充库

> 小场景的作用是让人物在没有大事件时仍然发生变化。每个微动作至少包含：一个具体物件、一次不说破的交换、一个轻微错位，以及一个可以在下一场被看见的状态变化。甜味不负责抹平旧账，笑点也不负责替代选择。

### MICRO-E19-01｜酸橘子：不问酸不酸

- **场景**：E19 御街夜市，接 GOU-E19-02。
- **动作**：沈蘅咬到酸橘子，面色只停一瞬；顾行舟不问，把自己包里的糖橘推给她，拿走她面前那瓣酸的。沈蘅不道谢，把糖橘掰半留给他。
- **错位**：顾以为自己藏得不动声色，沈蘅其实看见了，只是不拆穿；他以为她接受照料，她同时也在把照料还回去。
- **对白意图**：不必解释“我在关心你”；若需要一句，沈蘅只问：“你挑甜的，还是挑我不会皱眉的？”顾不答，继续吃酸的。
- **关系变化**：两人第一次在不谈案子的时间里完成互相照料，而不是单向保护。
- **连续性回收**：E19 散场保留最后一瓣；E23 中秋分食时，沈蘅主动把食物先分成两份，不再等顾替她挑。

### MICRO-E07-01｜雨伞先遮纸，不先遮人

- **场景**：E07 清明雨棚外，沈蘅和顾行舟携带刚抄好的旧记录。
- **动作**：顾把伞面压向记录簿，自己的半边肩膀淋湿；沈蘅把伞柄往中间推，顾又把伞推回纸上，两人一路把伞柄推来推去。
- **错位**：顾把纸当成必须保护的证据，沈蘅把“你也在伞下”当成必须说明的关系事实。
- **转折**：纸角还是被雨打湿，沈蘅没有责怪他，反而让他把湿角摊开；顾不得不承认“保护”并不等于控制所有天气。
- **后果**：旧记录出现一处可辨但不完整的水痕，成为 E12 雨夜旧信的视觉连续性；两人的站位从前后变成并肩。

### MICRO-E13-01｜端午香囊：结绳的人不说来处

- **场景**：E13–E16 端午前后，香药街或青鹞船坊。
- **动作**：沈蘅买到一个线头松开的素香囊，顾行舟接过来，只改了一个结，不解释手法；裴九娘看见结法，故意问他是不是又把船货当军粮捆。
- **错位**：顾想把旧军伍痕迹藏在一个小结里，裴用玩笑把它点出来，沈蘅没有立刻追问。
- **关系/背景变化**：顾的旧身份第一次以可爱的生活动作露出，不靠闪回说明；沈蘅把“看见”暂时留作记录，不逼他当街交代。
- **连续性回收**：该结法在 E19 加赏牌、E30 旧阵和 E34 公共引导线中再次出现，但每次都必须说明是相似手法，不直接等同于同一人。

### MICRO-E16-01｜船上姜片：递过去就收回来

- **场景**：E16 青鹞风雨前，裴九娘递来一小片姜；沈蘅嫌辣，顾行舟把姜片接过去含在自己嘴里，再把半片递回她的茶盏边。
- **错位**：顾想替她承担不适，沈蘅却把姜片夹回他碗里，要求他先把船绳看完；照料被重新放回各自职业责任上。
- **轻松点**：裴九娘看着两人推姜片，说：“船上只缺一只桨，不缺第三个人替你们传东西。”
- **剧情变化**：顾先完成绳结检查再喝茶，沈蘅也先记下吃水刻线；生活动作同时服务关系和船战前的证据准备。

### MICRO-E23-02｜中秋留席：酒盏不替人说话

- **场景**：E23 中秋家宴前，停云酒肆楼下。
- **动作**：顾行舟为那个不愿留姓名的旧脚夫多摆一只酒盏，来人离开后却不撤；沈蘅将自己的桂花酒分半盏过去，没有问“他是谁”。
- **错位**：顾把留席当成欠债的私人仪式，沈蘅把它看成一条需要标记来源的公共事实。
- **转折**：顾想把酒盏收进柜里，沈蘅按住盏沿：“可以不写姓名，但不能假装这席没人坐过。”
- **后果**：顾在“事实／推断／未证”之外增加“隐私理由”一栏；中秋团圆没有清除旧债，却让两人拥有共同的记录习惯。

### MICRO-E30-01｜冬夜暖碗：先给门外的人

- **场景**：E30 雪夜城门，药车尚未获准全部通过。
- **动作**：顾行舟把值房里唯一一碗热汤推给门外咳嗽的孩子，曹肃把碗推回门内，要求先登记；顾没有争抢，只把碗放在门槛中线，等梁成武完成交接。
- **错位**：顾的第一反应是救眼前人，曹肃的第一反应是守住可追责流程；两人都没有完全错误。
- **关系/剧情变化**：沈蘅若在场，只记录“谁先把碗放到哪里”，不替顾或曹肃判定善恶；E30 的旧同袍冲突因此从个人脾气转为制度选择。

### MICRO-E36-01｜“今日柳绿”：不替孩子解释

- **场景**：E36 春分后的春信屋。
- **动作**：孩子递来“西桥边，今日柳绿”。顾行舟顺手想补一句“可能是水位回落”，沈蘅抬手让他停；两人只写下时刻和地点。
- **轻松点**：顾看着纸，问：“这回也不许我猜？”沈蘅答：“猜可以，别写在别人名下。”
- **终局变化**：顾把自己“知道如何解释”的冲动留在纸外；两人的亲密最终表现为共同克制，而不是共同替世界下结论。

### 8.1 微场景投放规则

| 投放密度 | 使用方式 | 不能发生的事 |
|---|---|---|
| 每 2–3 集一次 | 选择一个食物、灯、伞、纸、绳、酒盏或衣物作为关系媒介 | 连续堆叠撒娇、暧昧或段子，导致主线停滞 |
| 大事件前 | 先用轻动作显示人物平时如何照料、回避或互相纠正 | 把轻松动作当成危险预告的唯一证据 |
| 冲突之后 | 让相同物件以不同方式回来，显示关系已经改变 | 用一次递食、牵手或道歉直接清零旧伤 |
| 节日前后 | 把仪式动作与职业劳动、公共规则或家庭分席相连 | 把宋代节日写成无人物选择的观光背景 |

## 9. 节日仪式场景卡

> 这些场景卡是可直接放入微短章的故事层执行稿。节日名称与现有时间轴对齐；“灯牌编号、听更、试灯、祭扫路线”等具体安排属于本项目的戏剧化解释，服务人物选择和城市因果，不宣称覆盖全部宋代礼俗。

### FEST-Y13-01｜上元旧夜：先点灯，还是先封桥

- **建议使用**：E10 旧案复核、E23 手稿分栏、E34–E35 复灯回收。
- **地点**：LOC-005 御街夜市、LOC-015 城门与桥闸查验口。
- **参与者**：沈蘅、顾行舟、曹肃、高问、柳十四；普通灯户和桥口执行者作为现场证人。
- **进入状态**：沈蘅拿到上元旧案半卷，只知道“灯市失火、桥口封闭、春信被禁”；顾行舟知道护送和封口的身体顺序，却不愿把自己的旧军伍位置说全。
- **仪式动作**：
  1. 灯户先验灯芯和挂绳，再把灯牌交给听更的人登记；每户只报自家看见的灯，不替邻户解释。
  2. 更鼓响后，桥口按“灯已稳／人可过／桥暂封”的顺序复述；曹肃只确认自己收到的那一段。
  3. 高问把公开榜、值房摘要和民间口述并排放置，沈蘅给每条标“亲见／转闻／待核”。
  4. 顾行舟看到旧灯牌背后的磨损绳结，先说“这能说明有人动过牌”，不说“我知道是谁动过”。
- **目标与阻力**：沈蘅想还原谁先改变了人流；顾行舟想保护仍活着的旧执行者；缺页、不同听更时刻和公众记忆互相抵牾。
- **转折**：一张桥口记录显示封桥时刻早于公开火情，证明“封桥”不是火灾后的单一反应；但它仍不能证明谁下令或谁故意延误。
- **选择与代价**：顾行舟交出自己记得的站位，不交出旧人的姓名；沈蘅接受隐私限制，却把“顾知道而未公开”单独列入关系与证据账。
- **退出状态**：上元从一场灾难回忆变成可复核的制度顺序；E34 的复灯不再追求“恢复旧热闹”，而是重写谁能报时、谁能纠错。

### FEST-E01-01｜惊蛰开铺：先扫门，还是先开匣

- **建议使用**：E01 开场，作为全季日常仪式的种子。
- **地点**：LOC-002 沈家香铺。
- **参与者**：沈蘅、陆清和、顾行舟、街坊。
- **仪式动作**：陆清和先扫掉门槛雨泥，再拨干灯芯；沈蘅按香材、灰色和刀痕整理旧匣；顾行舟把桌上尖锐的香刀移到远离客人的一侧。
- **轻微冲突**：陆清和要按旧规毁掉异常香丸，沈蘅要先留样；顾行舟不替母女决定，只把防风灯挂稳。
- **剧情后果**：黏合物“近半年才会出现”的物证从开铺动作里出现；人物第一次通过“是否遵守开铺旧规”展示保护与知情权冲突。
- **回收**：E36 春信屋仍保留“先记时刻、再解释”的开门规则。

### FEST-E07-01｜清明纸灰：名字写在谁手上

- **建议使用**：E07–E08，放在春台夜雨与失图追查之间。
- **地点**：LOC-007 西湖画舫靠岸处、LOC-008 西泠书坊与画铺外沿。
- **参与者**：沈蘅、顾行舟、柳十四、周砚之。
- **仪式动作**：清明人流散去后，柳十四把一张写给亡者的纸折好，不让周砚之直接替她补字；沈蘅把纸灰、原字和后来添写的字分三处放置。
- **目标与阻力**：沈蘅想确认一条旧话是否属于沈怀川；柳十四想保留写字人的称呼；周砚之想把残字补成完整图意；顾行舟只负责把湿纸移到干处。
- **转折**：残纸背面压出另一张图纸的纹路，说明有人把书写和绘图材料叠在一起，但不能直接证明谁改了图。
- **选择与代价**：周砚之放弃“替残字补完”的冲动，沈蘅把“不知道”写进档案；柳十四因此保住名字，却失去一次让故事更好听的机会。
- **退出状态**：祭扫不被写成亡者神谕，而成为“谁有权替别人补全”的关系与证据问题；E08 的失图追查获得纸张接触顺序。

### FEST-E13-01｜端午香囊：香气可以报货，不能报真相

- **建议使用**：E13–E16，承接 MICRO-E13-01。
- **地点**：LOC-003 香药街、LOC-011 青鹞与 LOC-012 船坊。
- **参与者**：裴九娘、沈蘅、顾行舟、阿七、香药摊贩和船工。
- **仪式动作**：端午前后家户买香囊、挂艾草；船工顺手检查缆绳和船钉；裴九娘把香囊线色作为自己的货包记号，却不把它当成官署封签。
- **目标与阻力**：沈蘅想区分节期需求造成的香药上涨与异常囤货；裴九娘要保住船期和货物；顾行舟想替她挡住旧船帮的嘲讽。
- **转折**：同一香囊线色出现在两批不同船货上，证明有人借民俗包装传递货路，但无法单凭颜色断定幕后人。
- **选择与代价**：裴九娘公开自己的吃水和船期记录，接受旧名声被重新翻出；顾行舟只改绳结、不替她解释。
- **退出状态**：端午仪式把香药、船货和职业劳动连在一起；E16 账匣沉水时，观众已经理解为什么一个香囊或绳结也可能是证据，但不是完整答案。

### FEST-E21-01｜七夕乞巧：谁来替谁写愿望

- **建议使用**：E21–E22，作为柳十四署名前的轻声部。
- **地点**：LOC-006 春台瓦舍后台与 LOC-005 夜市听曲排队处。
- **参与者**：柳十四、周砚之、沈蘅、顾行舟、年轻听客和后台艺人。
- **仪式动作**：听客把乞巧纸递给艺人，请她代写愿望；柳十四只替人誊写原话，不擅自润色；周砚之画台口灯花，柳指出画上没有后台缝衣人的手。
- **轻松冲突**：周砚之认真问“愿望要不要构图”，柳十四把笔递回他：“先问是谁的愿望。”沈蘅在旁边纠正纸上时间，顾行舟把墨水放到两人都够得着的位置。
- **转折**：一名席客要求柳十四把“今秋无忧”写进所有乞巧纸，柳没有当场唱反调，只把它标作“客人要求的词”，不署为自己的愿望。
- **选择与代价**：柳十四保住当晚演出的收入，却让“柳十四”与“柳望舒”之间的署名问题无法继续回避；周砚之不替她把后台画成理想舞台。
- **退出状态**：E22 的本名新曲有了生活准备：名字、愿望和曲词不能被最会说话的人代写。

### FEST-E19-02｜白露桂夜：听曲也要有礼数

- **建议使用**：E19 勾栏听曲五场段，与 GOU-E19-01 至 GOU-E19-05 合并使用。
- **地点**：LOC-005 御街夜市、LOC-006 春台瓦舍、LOC-009 停云酒肆。
- **仪式动作**：入场先报曲名、打板、奉茶、收赏；顾行舟替沈蘅挑靠门座位，她把他换到内侧；两人按席面礼数分酸橘，又在同一句“今日无事”中发现风险。
- **目标与阻力**：顾想在节气转换的桂夜做一次普通掌柜；沈蘅想在不破坏夜晚的前提下保留核验权；柳十四要区分自己的唱词和席客买来的安抚句。
- **转折**：加赏牌上的入仓时刻和“今日无事”同时出现，听曲礼数变成传播链；顾的旧军伍捆法又让他想起不能公开的靠山。
- **选择与代价**：顾交出“亲见／未证”两栏，沈蘅接受暂不公开席号；两人保住同行，却失去假装今夜真的与主线无关的资格。
- **退出状态**：E20 的北来流民登记可以从“粮有没有进城”继续追问“安心话术有没有先于粮食抵达”。

### FEST-E23-01｜中秋酒账：留席不等于替人圆满

- **建议使用**：E23–E24，与 BACK-E23-01 和 MICRO-E23-02 合并使用。
- **地点**：LOC-009 停云酒肆楼下、沈家香铺后院。
- **参与者**：沈蘅、顾行舟、陆清和、旧军需脚夫、零散酒客。
- **仪式动作**：中秋家宴先给长辈和未归的人留席；顾行舟为旧脚夫多摆一只酒盏；沈蘅把旧稿、桂花酒和“事实／推断／未证”三栏并排，不让团圆礼数替旧案下结论。
- **转折**：旧脚夫只叫顾一声“伍长”，留下石桥冬运缺签副记；顾试图把纸藏到酒坛后，沈蘅没有抢，只问他是否愿意让这席被记录。
- **选择与代价**：顾公开自己有靠山但不公开来人姓名；沈蘅保留隐私边界，也明确说“不能假装这席没人坐过”。
- **退出状态**：中秋的团圆感成为两人共同承担旧债的形式；E24 仍能共席，但不再用温柔消除顾行舟的隐瞒。

### FEST-E30-01｜冬至门槛：热汤先给谁

- **建议使用**：E29–E30，与 MICRO-E30-01 和 AX-10 合并使用。
- **地点**：LOC-015 城门、值房和侧门查验口。
- **参与者**：顾行舟、沈蘅、曹肃、高问、梁成武、药夫和门外伤员。
- **仪式动作**：冬至前后，值房按时落栓、记更、分汤；门内先留守门人份额，门外伤员的姓名和药名必须先登记。
- **目标与阻力**：顾行舟要救眼前咳嗽的孩子；曹肃要守住无正式改令不开整门的责任链；沈蘅要记录两种正确如何同时伤人。
- **转折**：顾把热汤放在门槛中线，曹肃没有把它踢回去，也没有擅自放行；梁成武完成交接，汤和药分别进入可追责流程。
- **选择与代价**：顾放弃以旧身份强行通行，曹肃放弃把门外人写成“未到”；药车仍然延误，两人的旧同袍关系从默契变成公开监督。
- **退出状态**：E31 断桥救援不再依赖一个人临时发善心，而能把“先给谁、谁签字、谁接手”写成公共动作。

### FEST-E31-01｜立春试灯：仪式被雨打断后怎么办

- **建议使用**：E31–E33，连接断桥、错灯和第一盏灯。
- **地点**：LOC-015 桥闸与查验口、LOC-018 城南安置区。
- **参与者**：林阿沅、裴九娘、顾行舟、梁成武、普通居民和灯户。
- **仪式动作**：立春前后试挂灯号，先试颜色，再试声音、触感、时刻和更正规则；灯户把坏灯、湿灯和错灯分别登记，不把失败灯当成不吉之兆。
- **目标与阻力**：阿沅想让普通人能回传错误；裴九娘要保证水边灯号不会被雨幕吞掉；顾行舟想直接替大家安排站位，却被裴要求把绳线交给脚夫。
- **转折**：暴雨把一盏标准灯浇灭，另一处普通人用敲木板和触绳回传“桥断”；单一颜色规则失效，但公共协议没有失效。
- **选择与代价**：顾把自己的判断拆成可复用手势和退路，不保留个人解释权；阿沅把“误判”写入新年第一份失联表。
- **退出状态**：仪式不再是“灯亮即吉”，而是“错误能被报回”；E34–E35 的复灯从庆祝转为测试。

### FEST-E35-01｜春分复灯：人人都要会报一盏灯

- **建议使用**：E34–E36 终局。
- **地点**：LOC-015 城门、LOC-014 三仓、LOC-018 安置区之间的公共通道。
- **参与者**：沈蘅、顾行舟、曹肃、高问、梁成武、柳十四、船工、脚夫、医者、孩子。
- **仪式动作**：正式改令公开签押；伤员、急药、家属和普通通行分别过线；每条线都由不同职业的人复述方向、时刻和更正规则。
- **目标与阻力**：众人想重新拥有节日热闹；旧制度习惯想把“复灯”变成唯一正确答案；顾行舟必须阻止自己再次成为唯一指挥者。
- **转折**：一名孩子把无危机的“今日柳绿”递进春信屋，几个人都想解释，沈蘅只让大家写时刻和地点。
- **选择与代价**：顾行舟不再站到最前面宣布答案，而是把退路、绳线和手势交给普通节点；旧身份公开，个人安全与隐姓生活不可恢复。
- **退出状态**：上元旧伤被重新编排成可纠错的公共仪式；E36 用日常短句证明系统能记录而不擅自解释。

## 10. 仪式场的统一交付字段

每个节日或仪式场进入逐场剧本前，除常规字段外，必须补齐：

`ritual_name / ritual_owner / public_rule / private_deviation / object_or_gesture / participant_choice / changed_state / causes_next / continuity_refs`

仪式场必须回答四个问题：谁在主持、谁被排除、谁可以纠正、仪式结束后什么已经不能恢复。这样上元的灯、端午的香囊、中秋的酒盏和立春的试灯才会成为剧情动作，而不是时代装饰。
