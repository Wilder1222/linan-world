# 《临安春信》故事线节奏与悬疑翻转修订 v2

> 状态：`FOUNDATION-DRAFT`
>
> 目的：在不改动既有世界观、人物层级、六篇结构和结局价值的前提下，把 36 集母版从“事件连续发生”提升为“因果连续推进”。本文件采用欧美剧的因果推进、韩剧的关系回报与情绪悬念，但不模仿任何具体作品。

## 1. 唯一戏剧问题

当公开信息曾经害死人、集中信息又正在害人时，沈蘅能否在灾难扩大前建立一套**能迅速行动、来源可追、错误可改、隐私受保护且无人垄断**的春信？

每一集都必须让这个问题发生一次具体变化：

`发现异常 → 形成判断 → 判断伤到人 → 人物重新选择 → 新信息改变下一集目标`

不能只用“又发现一条线索”推进。

## 2. 新的单集节奏

每集约 45 分钟，采用“冷开场 + 四段因果 + 情绪尾钩”：

| 段落 | 时长 | 必须完成 |
|---|---:|---|
| 冷开场 | 2–4 分钟 | 先给一个可解释但未解释的异常/后果；不得使用欺骗观众的假闪回 |
| 第一段 | 8–10 分钟 | 主角主动设定目标，明确本集要查什么、保护谁、会失去什么 |
| 第二段 | 10–12 分钟 | 第一种解释被事实或关系推翻；A 线与 B 线发生真实碰撞 |
| 第三段 | 10–12 分钟 | 角色必须在两个都合理的选择中舍弃一个；选择改变权力或关系位置 |
| 第四段 | 8–10 分钟 | 本集问题局部闭环，同时兑现一个前置线索并打开下一层问题 |
| 情绪尾钩 | 1–2 分钟 | 不是单纯“发现更大阴谋”，而是一个人知道了会改变关系/行动的事实 |

每一段都要满足：

`目标 → 对抗 → 选择 → 状态改变 → 下一段因此发生`。

如果删掉一场戏，后面的目标、知识、关系或行动不受影响，这场戏就不是因果戏，应改成日常扩展或删除。

## 3. 三条同时运行的线

### A 线：城市悬疑

每集回答一个小问题，又把答案升级为下一层问题。悬疑分六层：

1. **物证异常**：香材、粮尘、曲词、地图、船重；
2. **传播异常**：谁在重复、改写、截断信息；
3. **供应异常**：粮、水、药、船与仓储的系统关系；
4. **历史异常**：十三年前的记录为什么互相矛盾；
5. **制度异常**：谁有权汇总、封锁、删改和解释；
6. **修复异常**：系统如何在犯错后自己发现并改正。

### B 线：关系选择

每集至少有一段关系从“亲近/信任/亏欠/依赖/敬意/怨恨/共同秘密”七维中的两维发生相反变化。例如亲近上升但信任下降，或敬意上升但依赖下降。

### C 线：生活与职业

每集至少一个职业动作既推进当集调查，又改变普通人的生活；终局能力必须在这里先被看见。

三线不允许互相解释同一件事：A 线给事实，B 线给代价，C 线给可见生活。

## 4. 悬疑与翻转规则

### 4.1 公平线索

每个主要翻转至少有四个阶段：

| 阶段 | 写法 |
|---|---|
| 播种 | 观众第一次看见，但可有普通解释 |
| 误读 | 人物基于欲望/恐惧作出合理错误判断 |
| 复核 | 另一职业节点提供不一样的证据 |
| 重义 | 真相改变人物关系或行动，而不只改变知识 |

禁止凭空出现的幕后录音、失忆、隐藏血缘、突然全知或“其实一直有另一份证据”。

### 4.2 翻转的五种类型

1. **事实翻转**：香丸不是十三年前保存，而是近期放入；
2. **动机翻转**：宋惟敬不是为了夺权，而是为了避免重演妻儿死亡，但动机不能免除后果；
3. **责任翻转**：裴九娘不是失信者，然而她也曾选择沉默；
4. **价值翻转**：集中调度确实救过人，民间横向网络也确实会误传；
5. **情感翻转**：顾行舟的保护是真爱，同时也是剥夺选择；陆清和的隐瞒是保护，也伤害了女儿。

### 4.3 反转后的硬约束

反转不能取消已经发生的代价。它只能重新解释代价由谁造成、谁承担、谁有机会修正。

## 7. 情感推进的韩剧式回报规则

情感不再只在大冲突中推进，每三集必须完成一次“日常回报”：

- E01–E03：留灯、改曲、共享一条未经证实但被标记的记录；
- E04–E06：第一次主动等待、第一次承认“我可能错”、第一次把秘密交给对方保管；
- E07–E12：共同雨伞、半卷旧案、保护性隐瞒造成的第一次伤害；
- E13–E18：修船不安慰、逐户更正、五人第一次不站在同一边；
- E19–E24：桂花夜、相亲与前程、旧稿共同阅读；
- E25–E30：决裂不靠第三者，靠真实价值冲突；
- E31–E36：并肩救灾但不清零旧账，最后以“你去哪”完成爱与主体性的回报。

每次情感回报必须改变下一次选择；不能只增加甜度。

## 8. 反派与对手的专业写法

宋惟敬、黎见山、贺兰度不是同一类反派：

- 宋惟敬代表“一个可靠的人替所有人负责”；
- 黎见山代表“没有利润和控制就无法救人”；
- 贺兰度代表“如果不制造政治压力，北方会被遗忘”。

他们都必须至少有一次真正有效的解决方案，让观众短暂希望他们是对的；他们的失败来自优点扩大成伤害，而非突然变坏。

## 9. 转场到逐场剧本的硬字段

之后每个微短章/场景必须补齐：

`objective / obstacle / choice / changed_state / causes_next / subtext / relationship_delta / continuity_refs`

这些字段没有填满前，不进入对白、分镜和 AIGC 生成。
