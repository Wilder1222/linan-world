# 群像终局回响矩阵

## 终局设计原则
每个职业能力必须先在日常中出现，再在灾难中回响。

- 修伞匠的竹骨 → 灯架
- 洗衣妇对衣物泥痕的知识 → 找人、辨路线
- 馄饨铺的赊账与饭量 → 独居/失联基线
- 脚夫的身体计数 → 搬运链
- 装裱匠对纸布材料的知识 → 耐雨地图
- 妆娘的清洁、认脸与后台组织 → 伤员身份确认
- 更夫的时间节奏 → 消息时序确认
- 寺院行堂的分流经验 → 避免领取踩踏
- 客栈女使对床铺和行李的记忆 → 外来人口名单

## 终局情感规则
危机不会自动让旧关系和解。

- 沈蘅与顾可以一起救人，仍然没有完全修复信任；
- 许含章可以把儿童交给贺兰度护送，仍然不替他求情；
- 黎令仪可以去看受审的养父，仍然亲手交证据；
- 民间可以接受高问指挥疏散，仍记得他执行过封锁；
- 船帮可以跟裴九娘走安全水路，仍有人叫她‘失信九娘’。

这能让最终的团结不是廉价‘大家都是一家人’，而是更成熟的：

> **我们仍然有旧账，但眼前这个人必须先活。**
