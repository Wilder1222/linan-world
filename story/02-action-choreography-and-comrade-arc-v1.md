## 1. 男主修订设定

### 顾行舟｜CHR-L1-05

- **Y0 身份**：29 岁，停云酒肆掌柜；曾任边军粮药护送队的押运伍长，退役后做过民间护送与短途镖运。
- **服役时间**：Y-12 入边军，Y-7 经历“石桥冬运”旧事，Y-4 因旧伤与对命令后果的失望退役，Y-3 至 Y-1 做民间护送，Y0 在临安经营停云酒肆。
- **实际能力**：识别车马与水路风险、安排撤退顺序、夜间守望、绳结与简易固定、短兵器近身自卫、在混乱中给出简短可执行的分工。
- **能力边界**：没有现役军权；不能调兵、开城、替官署签押，也不能一人击溃多人。面对三人以上的持械冲突，他的第一选择是利用门、车、船、绳、货物和人流脱离，而不是硬拼。
- **动作气质**：先看出口，再判断谁最需要撤离；短刀只用于逼退、割绳、挡击和脱身。动作短、重心低、借力多，赢的标准是让人活着离开，不是把对手打倒。
- **身体代价**：右眉浅旧伤、手背旧刀绳伤沿用现有角色锚点；新增连续性是右肩在寒雨和长时间用力后发紧，E16、E28、E31 三次动作中分别加重，不能突然恢复成无伤状态。
- **随身物**：退役后不穿军服、不佩现役腰牌；酒肆账柜深处保存一块磨损的旧军牌和一柄不再开锋的短刀。短刀不承担“神兵”功能，只是他不愿再交回军营的旧物。

### Y-7“石桥冬运”旧事

这是顾行舟边军背景的情感根，不是新的城市阴谋主线。

1. 边军护粮队在雪夜接到封桥护粮令，命令本身有保住军粮和避免全队被截的合理性。
2. 顾行舟在桥下发现掉队的伤兵、脚夫和一户带孩子的百姓；他回身救人，导致一辆粮车翻入浅沟，队伍损失补给并延误半个时辰。
3. 曹肃留在桥头执行封桥与掩护；他没有出卖顾，也没有替顾改写结果。两人因此互相欠命，也互相不肯替对方洗白。
4. 高问当时负责随队军需文书，记录了“回身救人、粮车翻覆、伤员人数”三项事实，后来上报摘要删掉了回身时刻，只留下“运粮失误”。
5. 梁成武是队中年长的旧兵，曾把顾从冰水里拖出来；如今在城门当军士。他记得顾的本事，也记得顾当年让整队承担的损失。
6. 顾退役不是因为一次英勇获奖，而是因为他发现“守住多数人的粮”与“眼前的人该不该被丢下”不能靠一句军令自动解决。

这段旧事在 E10、E12、E19、E23、E30、E34 分层露出：先露动作习惯，再露旧军令，最后让同袍各自留下事实与责任。任何闪回都只提供当时人物已经看见的局部，不把顾写成全知证人。

## 3. 全季动作原则

### 3.1 动作场的因果公式

每个动作场必须完成：

`目标 → 地形阻力 → 职业动作 → 对手改变策略 → 主角选择 → 可见代价 → 新线索或新关系状态`

“打赢”不能作为唯一结果。可接受的结果包括保住一张货签、让一个人撤离、让证据变形、暴露旧身份、失去合约、留下伤势、或让同伴不再盲从。

### 3.2 兵器与工具

- 顾行舟：未开锋短刀、短棍、门栓、酒肆托盘、护货绳、货车横木。短刀出现时，优先是挡击、割断危险绳索或制造退路。
- 曹肃与城门军伍：长枪、木盾、门闩、绳栏和手势阵列。军伍的强处是分工和封口，不是个人比武。
- 裴九娘与船工：篙、船钩、缆绳、桨、湿船板。船战的危险来自失足、船体摆动和货物移动。
- 普通人：扁担、竹篮、门板、布包、木箱、推车。普通人可以形成阻挡和传递，但不会突然获得武力等级。

### 3.3 不写成武侠奇观的四条线

1. 不出现踏水、飞檐、隔空点穴、以一敌百和无伤落地。
2. 不让女主或普通群众为了爽点突然获得未经建立的武力。
3. 不用血腥伤口替代戏剧后果；伤势必须影响下一场的劳动、关系或判断。
4. 每次动作前都让观众看见一个可利用的现实条件：湿木、低门、窄桥、绳结、货车、潮向、火盆、仓门或人流缝隙。

## 4. 12 个动作锚场

以下场景是 36 集正式剧本的动作骨架。场次与微短章编号由 Episode Gate 绑定；本稿先锁定剧的目的、动作、代价和连续性。

### AX-01｜E02《香箱藏粮》｜码头仓廊夺签

- **地点**：LOC-010 钱塘码头，湿木栈道与临时香箱堆位之间。
- **参与者**：顾行舟、沈蘅、两名临时脚夫、一个带头搬运人、围观船工。
- **进入状态**：沈蘅只想追到货路；顾行舟知道对方更可能抢货签而不是抢整箱货。
- **目标**：保住能证明“香箱夹粮”的半张货签，并让沈蘅退到干燥位置。
- **动作节拍**：
  1. 顾先用余光确认桩柱、空船和退向仓门，提醒沈蘅不要追第一个跑的人。
  2. 带头搬运人用肩撞开他；顾不拔刀，借退步把货车横木卡在两人之间。
  3. 第二人伸手扯油布，顾用护货绳绕住车轮，不锁人，只让货车停住；沈蘅趁停顿压住货签边角。
  4. 第三人抡起短钩，钩尖撕开顾的袖口。顾用空竹筐挡一下，筐裂，脚下退到有水的木板。
  5. 带头人改抢沈蘅手里的纸；顾用肩膀顶开距离，却看见先前被推倒的脚夫滑入水沟。
  6. 顾放弃追带头人，先把绳头递给落水脚夫；沈蘅用香粉在半张货签背面做记号。
  7. 对方带走另一半货签，围观船工开始议论沈家货路，冲突没有被“打赢”。
- **选择与代价**：顾选择救一个并不认识的脚夫，失去追上带头人的时机；袖口被撕、前臂擦伤，沈家只保住半张签。
- **对白节点**：顾：“纸能补，先把人拉上来。”沈蘅：“你放走了他。”顾：“我看见的是另一个没站稳的人。”
- **退出状态**：半张货签成为线索；沈蘅第一次看到顾的护送不是逞强，而是排序；顾的身份仍未暴露。
- **连续性**：E03 前清理前臂擦伤；半张货签背面的香粉记号必须进入后续货路核对。

### AX-02｜E05《青鹞入巷》｜雨泊船板交锋

- **地点**：LOC-010 钱塘码头至 LOC-011 青鹞之间的窄跳板。
- **参与者**：顾行舟、裴九娘、石六、旧船帮两名拦路人、阿七。
- **进入状态**：裴九娘要把水路记录带上船；顾本能地站在她身后，把“保护”做成了挡路。
- **目标**：让裴和记录安全登船，不让冲突扩大成船帮械斗。
- **动作节拍**：
  1. 雨水把跳板压得发亮；裴先试脚下，顾却先横身挡住她与船钩之间的空隙。
  2. 裴一句“别挡我的路”逼他侧开半步；第一名拦路人借船钩推来，顾用短棍压低钩柄，让钩子滑向空处。
  3. 第二人扯缆绳，青鹞船头偏移；裴不救自己的记录，先把缆绳绕回桩上，石六用肩膀顶住跳板。
  4. 顾借桩柱转身，肩背撞上船舷，短刀只割断缠住阿七脚踝的旧麻绳。
  5. 旧船帮忽然不再抢人，而去抢裴腰间的记录袋；裴立刻把袋子塞给石六，自己用船篙隔开。
  6. 顾看见对方使用的是旧军伍的“收队”手势，短暂失神；裴用篙柄敲响船板，召集船工而不是让顾继续单打。
- **选择与代价**：顾听从裴的要求退到并肩位置，不再替她挡在前面；右肩旧伤复发，裴的外层水路记录被雨水打湿。
- **对白节点**：裴：“你护的是我，还是你心里那支队伍？”顾：“先护船板上的人。”裴：“那就站旁边。”
- **退出状态**：旧船帮确认顾受过边军训练；裴与顾的关系从“被保护”转为“共同站位”。
- **连续性**：E06 顾右肩不抬高取物；湿记录只能保留封面与部分字迹，不能在后文恢复成完整原件。

### AX-03｜E08《西湖失画》｜书坊后廊追图

- **地点**：LOC-008 西泠书坊与画铺，木架、晾纸绳和狭窄后廊。
- **参与者**：顾行舟、周砚之、柳十四、偷图者、两名书坊伙计。
- **进入状态**：周砚之想保住旧水图完整，柳十四想先追人；顾只知道纸边不能碰湿墨。
- **目标**：拿回旧水图，不让追逐把整间书坊变成火灾和踩踏。
- **动作节拍**：
  1. 偷图者夹着画卷从晾纸绳下钻过，柳十四用合上的扇面打落一盏差点泼墨的罩灯。
  2. 顾不追到屋顶，先关半扇低门，把人流压到一条可控的后廊。
  3. 偷图者用图筒横扫，顾侧身让过，图筒撞在木架上；周砚之抢到卷尾，却不敢用力。
  4. 柳把一匹未干的布帘甩到出口，偷图者改走墨盆边；顾用长凳挡住脚，不碰对方脖颈和头部。
  5. 对方突然抛出一卷伪图，周松手去接，真正的旧图被带头冲向雨廊。
  6. 顾选择护住周和纸架，偷图者踏上湿石阶逃走；周从伪图的折痕里看出真正目标是地下水路。
- **选择与代价**：顾不为追人撞翻书坊，保住大部分纸张但放走偷图者；周的旧图一角撕裂，柳对顾的克制产生敬意。
- **对白节点**：周：“他要跑了！”顾：“图先落地，人才能继续追。”柳：“你们两个终于有一句话说的是同一件事。”
- **退出状态**：偷图者身份未明，但水路出口成为明确目标；周不再把顾当只会挡人的掌柜。
- **连续性**：旧图缺角在 E21 的道路图核对中仍存在；顾的动作不得出现跳上屋脊等超出地形的移动。

### AX-04｜E12《雨夜旧信》｜桥口护送

- **地点**：LOC-010 码头外的窄桥、雨幕下的废弃渡棚。
- **参与者**：顾行舟、裴九娘、幸存者、两名追信人、远处接应的船工。
- **进入状态**：裴手里有足以洗清旧名声的原信，但原信还牵涉幸存者身份；顾只知道必须先把活人送进渡棚。
- **目标**：让幸存者和信件都离开追击范围，同时不公开幸存者姓名。
- **动作节拍**：
  1. 顾用破油布把桥面分成可走和不可走两段，先把幸存者安排在靠里侧。
  2. 追信人从桥头逼近，顾用短刀背挡开第一记棍击，脚不离开桥板中心，避免把人撞下水。
  3. 裴把信塞入防水布套，转身用船篙顶开第二人；两人的动作互相补位，不形成顾单独护送。
  4. 一名追信人用旧军伍的收队手势，顾看出对方不是临时地痞，而是熟悉护送流程的人。
  5. 顾被叫出旧称，短暂停顿；幸存者趁隙跌向桥栏，顾放弃追击，抓住对方衣带把人拉回。
  6. 裴用船钩勾住漂走的信套，外层封纸被水冲破，但内层纸仍在；追信人借雨撤走。
- **选择与代价**：顾选择活人而不是完整信封；信件外层路线信息损坏，旧身份暴露给至少一名追信人。
- **对白节点**：追信人：“边军的人，也替人捡信？”顾：“退下来以后，才知道信落水也会带人一起沉。”
- **退出状态**：裴保住证据核心，却不能最快洗清自己；顾的旧同袍线从暗处进入主线。
- **连续性**：幸存者姓名仍受保护；E13 起顾不再把旧身份说成与自己无关。

### AX-05｜E16《青鹞沉信》｜沉船抢人

- **地点**：LOC-011 青鹞，逆风雨水道，船板湿滑、货箱移位。
- **参与者**：顾行舟、裴九娘、阿七、落水乘客、一名趁乱抢账匣的人。
- **进入状态**：账匣可能含运输副账；乘客落水，阿七想跳水，裴必须同时稳船。
- **目标**：先把落水者拉回船边，避免青鹞侧翻，再决定账匣是否还能追回。
- **动作节拍**：
  1. 船身一歪，顾先把酒桶推到低侧压舱，顺手把阿七的衣领拽回船内。
  2. 抢账匣的人趁船板混乱冲向舱口，裴用篙横挡；顾不追账匣，先把救生绳绕过桅柱。
  3. 落水者抓住船舷，顾俯身时右肩发紧；阿七按顾此前教过的三段拉绳节奏，和裴一起把人往上送。
  4. 抢匣者用木桨击打顾的背部，顾转身用前臂格住，借船板倾斜把对方逼回舱角。
  5. 账匣从舱口滑落，裴伸篙去勾，船头撞上暗桩；她立刻割断一条货绳，避免整船被拖横。
  6. 顾看见账匣沉入水中，仍松手去托住落水者最后一截衣袖；抢匣者跳入另一侧小舟逃走。
  7. 船工把人拉上来，阿七没有继续追匣；封签上的仓号被落水者记住。
- **选择与代价**：裴先救人，顾支持这一选择；青鹞撞坏船舷，顾右肩旧伤加重，账匣沉失，证据链从物件转为记忆。
- **对白节点**：阿七：“匣子没了！”顾：“人先喘气。”裴：“今晚谁也别替我说后悔。”
- **退出状态**：账匣消失但仓号留下；顾和裴第一次在同一件事上主动放弃“证据完整”。
- **连续性**：E17 顾不能用右臂完整提重物；青鹞破损进入修船线，不得下一场无痕复原。

### AX-06｜E20《北客》｜安置点推车冲突

- **地点**：LOC-018 城南安置区，施粥棚、推车和临时木栏之间。
- **参与者**：顾行舟、贺兰度、许含章、一名想回北方的老人、一名只想留下的母亲、郑北鸿与几名激进青年。
- **进入状态**：激进青年想把一车粮改作“北归行动”的筹备物资；现场每个人的去留意愿不同。
- **目标**：让粮车不被抢走，也不让顾把自己的判断变成新的命令。
- **动作节拍**：
  1. 顾先看推车轮距和人群出口，站到车侧而不是车前，避免把人群压成一堵墙。
  2. 郑北鸿抓住车把，顾用手掌压住木把，不夺，只说先让推车后的人站稳。
  3. 一名青年抡起扁担，顾用空麻袋挡住，扁担砸破袋角；他顺势把麻袋拖到两人之间，形成缓冲。
  4. 贺兰度喊“我们的人”，顾立刻接话：“先问这车给谁。”这句话让贺兰度无法用口号接管现场。
  5. 那名母亲从人群里走出，说她只要孩子今日的粮，不参加任何北归行动；许含章把她的原话写进登记板。
  6. 顾松手退开，郑北鸿因失去人群支持而放下扁担，但仍记住顾的军伍站姿。
- **选择与代价**：顾把决定权交回具体领粮者，粮车保住但自己被认出受过军伍训练；贺兰度第一次正面面对“代表”与“替人决定”的差别。
- **对白节点**：顾：“你要救的是一车粮，还是一群人的名字？”贺兰度：“你说话像军令。”顾：“所以我现在不下令。”
- **退出状态**：激进派开始调查顾的旧身份；顾与贺兰度从理念争论进入共同承担具体人的冲突。
- **连续性**：E21 仍有人称顾为“边军掌车的”；不得把这场写成激进青年突然洗白。

### AX-07｜E22《本名新曲》｜后台逼签

- **地点**：LOC-006 春台瓦舍后台，戏箱、垂帘、上台侧门。
- **参与者**：柳十四、顾行舟、顾念娘、两名催签的席间仆从、乐工。
- **进入状态**：柳决定以柳望舒署名；席间仆从要她立刻交出曲稿并恢复指定曲。
- **目标**：让柳保住自己的曲稿和上台选择，不让酒肆掌柜替她把冲突打成私斗。
- **动作节拍**：
  1. 仆从堵住后台窄门，顾先把戏箱挪离火盆，避免争执引燃布景。
  2. 第一人伸手夺稿，顾抓住对方手腕后立即松开，改用戏箱盖隔出距离。
  3. 第二人从侧面推来，顾退到垂帘后，柳用合扇打掉落在地上的发簪，避免有人踩倒。
  4. 顾要上前，柳抬手止住他；她把曲稿折成袖中一小页，走向上台侧门。
  5. 仆从追到门边，顾只用门闩横住门缝，给柳留出一条能上台的线，没有把人压在门上。
  6. 乐工停半拍，柳在半拍里报出自己的本名；后台的肢体争执被她转成公开选择。
- **选择与代价**：顾接受柳“不由你替我出手”的边界，放弃把对方赶出后台的冲动；柳失去头牌位置，顾与春台关系变差。
- **对白节点**：柳：“你若替我打出去，台上唱的还是别人写的我。”顾：“那我只替你守住门。”
- **退出状态**：柳以本名上台，私抄版本的传播具备情绪起点；顾第一次在亲密关系里主动站开。
- **连续性**：顾没有造成仆从重伤；E23 后台仍保留被撞裂的戏箱角，作为柳失去头牌的物质痕迹。

### AX-08｜E26《封水》｜桥闸前的短兵相持

- **地点**：LOC-015 桥闸与查验口，湿石台阶、封水木栏、药船缆绳。
- **参与者**：顾行舟、裴九娘、曹肃所部两名军士、桥闸水工、急着送药的船工。
- **进入状态**：高风险水段确实需要停航；裴要提交分段方案，顾担心封水把药路一并切断。
- **目标**：阻止人群在湿桥上挤成一团，把药船和人员分成可复核的两条通行线。
- **动作节拍**：
  1. 顾先把药箱从桥心移到上风侧，确认缆绳不会扫到排队人群。
  2. 一名押栏军士误把裴的靠近当作冲闸，长枪横出；顾用短刀鞘格开枪杆，不碰枪尖。
  3. 曹肃喝止部下复述原令，裴趁空隙把高风险航段和必要药路分别写在两块木牌上。
  4. 船工拉缆过急，药船横摆；顾和裴同时压住缆绳，桥闸水工用木楔固定，不让顾独自承担。
  5. 顾发现只要割断一根旧货绳就能把药船拉回安全水面，却也会损失一批货包。
  6. 他割绳救人，药包散落；曹肃没有放行整船，只登记伤情和损失，让限制留下责任链。
- **选择与代价**：顾选择解除现场危险而非强行闯过封水线；裴失去商号合约，顾再次被旧同袍记录在案。
- **对白节点**：曹肃：“你要闯门？”顾：“我要让门知道它挡住了什么。”曹肃：“那就写清楚，不要只拔刀。”
- **退出状态**：封水仍然成立，但出现分段通行和责任记录的可执行方案；顾与曹的冲突从肢体边界转成制度边界。
- **连续性**：顾的短刀用于割绳，不用于攻击军士；药包损失进入 E27 的供应压力。

### AX-09｜E28《粮仓火》｜烟仓救人

- **地点**：LOC-014 三仓，违规灯油起火后的仓门、粮袋间和水桶线。
- **参与者**：顾行舟、黎令仪、黎见山、被困账房、仓场守夜、试图抢残页的纵火者。
- **进入状态**：火已从账册堆蔓到违规灯油；黎令仪必须在残页和账房之间选择，顾只能帮助建立退路。
- **目标**：先打开被烟压住的侧门并把人送出，不让顾的追击抢走黎令仪的选择。
- **动作节拍**：
  1. 顾把湿布分给守夜人，按旧护送队的两人一组方式安排水桶和退路，但不冒充仓场负责人。
  2. 纵火者从账房侧冲出抢残页，顾在粮袋间截住；两人用木板和麻袋推挡，脚下始终避开火盆油迹。
  3. 顾压住对方手臂时看见屋梁裂响；他松手转身，先把一名被困账房从低窗拖出。
  4. 纵火者趁烟逃走，黎令仪从灰里抢出少量残页；黎见山站在火线外，第一次无法用“可控损失”解释现场。
  5. 顾用仓门横木撬开侧门，右肩旧伤剧痛；守夜人接手抬人，顾不把人独自背出。
  6. 火势切断一排货袋，众人只能放弃货物，水桶线转向隔火而不是灭尽整场火。
- **选择与代价**：顾放弃追纵火者，选择救出账房；账册只剩残页，顾吸入烟尘、右肩发作，粮食损失转为真实短缺。
- **对白节点**：黎令仪：“那个人带着账跑了！”顾：“先把能说话的人抬出去。账要活着的人替它对。”
- **退出状态**：纵火责任仍需复核，但“人为点火＋违规储存失控”同时成立；黎令仪的残页成为下一场互证材料。
- **连续性**：E29 顾持续咳嗽，不能马上恢复酒肆日常；残页边缘有烟熏和水痕。

### AX-10｜E30《雪夜断信》｜顾行舟与曹肃的旧阵

- **地点**：LOC-015 外城门侧门，雪水、门闩、封锁木栏和一辆停滞药车。
- **参与者**：顾行舟、曹肃、梁成武、裴九娘、两名药夫、门外等待的伤员。
- **进入状态**：顾想把药车带到医棚；曹肃没有正式改令，不能开门；梁成武认出两人的旧军伍站位。
- **目标**：让药车不被雪夜和人群挤坏，并把“能否放行”的选择变成可记录的例外，而不是私人通融。
- **动作节拍**：
  1. 顾用车轴和木栏留出一条窄退路，裴把药包按轻重分成两堆，准备无法全运时先保急药。
  2. 顾向侧门移动，曹肃用长枪横住门缝；两人都不出刃，先用站位试探对方是否会越过界线。
  3. 顾借门柱逼近，曹以枪杆压住他的手腕；顾转身让枪杆滑过，短刀仍留在鞘内。
  4. 梁成武看出顾要走旧护粮队的换位，立刻把伤员车轮从两人之间拉开，避免同袍冲突伤到旁人。
  5. 门外传来孩子咳声，顾和曹同时停手；顾要求曹把人数、药名、时刻写入值房，曹拒绝在没有改令时开整扇门。
  6. 裴把一小包急药交给门内军士，由梁成武负责接收并签名；药车仍不能全部通过。
  7. 顾在雪地留下姓名和旧身份，曹把冲突记录为“未放行的药车与部分例外交接”，两人没有互相洗白。
- **选择与代价**：顾放弃强闯，曹放弃把一切写成“无人来过”；药车延误、两人受轻微擦伤，旧同袍关系从默契转为公开监督。
- **对白节点**：顾：“你拦的是我，还是这车药？”曹：“我先拦你，再把药写进去。否则明日谁都能说没见过。”
- **退出状态**：小部分急药进入门内，完整救援仍失败；顾的旧身份进入正式记录，为 E34 的公开改令埋下条件。
- **连续性**：顾的手腕在 E31 仍有淤痕；曹肃保留这页未删记录，不能在后文假装两人没有交手。

### AX-11｜E31《立春暴雨》｜断桥绳线

- **地点**：LOC-015 断桥与 LOC-018 城南安置区之间，急水、断木、倒下的车和临时绳线。
- **参与者**：顾行舟、裴九娘、林阿沅、梁成武、失联名单上的家属、数名脚夫和孩子。
- **进入状态**：官方图仍显示桥可通；桥已经断开，货物、名单和人群同时向低处滑。
- **目标**：先建立单向撤离线，再找失联者；不能为了抢回所有货物让绳线承受过重。
- **动作节拍**：
  1. 顾先看桥墩和上游漂木，选择把主绳固定在一辆空车轴上，而不是固定在摇晃的木栏。
  2. 裴用船钩把绳头送到对岸，阿沅把失联名单按已见、未见分开，不让“没找到”被写成“已安全”。
  3. 一名家属为追孩子冲入急水，顾用绳套勾住对方衣带，梁成武从岸上反向拖拽；两人共同承受冲力。
  4. 货车被水推来，顾割断装粮车绳，货物顺流而下，绳线因此保住。
  5. 顾右肩旧伤发作，短暂失去抓力；裴没有把他拉回安全处，而是把备用绳交给脚夫，让撤离继续。
  6. 最后一名孩子被送过后，阿沅发现名单上仍缺一个名字；救援成功不被写成问题全部解决。
- **选择与代价**：顾割断货车绳，优先保人和撤离线；损失一车物资、手掌被绳磨破，桥断事实得到无法抵赖的现场证据。
- **对白节点**：阿沅：“这车粮没了。”顾：“先把绳上的人留下。”裴：“下一根绳，换个人握。”
- **退出状态**：民间节点在无春信命令下开始协作；顾的旧军伍能力转成可交接流程，而不是个人英雄动作。
- **连续性**：E32 顾不能长时间握绳；断桥和货车损失进入 E33 的错灯调度。

### AX-12｜E34–E35《开城／万家春灯》｜旧阵改成人流

- **地点**：LOC-015 城门、桥闸与查验口，连接 LOC-014 三仓和 LOC-018 安置区的多段通道。
- **参与者**：顾行舟、曹肃、高问、梁成武、黎见山、贺兰度、船工、脚夫、医者与普通居民。
- **进入状态**：门终于可能打开，但水、粮、药和谣言同时压向门口；任何一个人单独“勇闯”都会制造新的拥堵。
- **目标**：把旧军阵改成四条可被普通人理解的引导线：伤员、急药、撤离家属、普通通行；每条线有记录人和交接点。
- **动作节拍**：
  1. 曹肃先复述正式改令，高问把原令、删节摘要和反签时间摊开；顾不接管军阵，只指出哪一处木栏会把人流逼向积水。
  2. 梁成武用旧军伍手势示范“停、让、转”，随后把手势教给没有军籍的脚夫，军令动作变成公共引导动作。
  3. 有人趁门开抢粮，顾用门板与车轴隔出缓冲，不追打；黎见山把第三仓真账交给两名不同路线的记录人。
  4. 贺兰度的激进青年试图截走一车粮，贺兰度本人先让出路线并公开地下撤离口；顾没有替他宣布悔过。
  5. 一名医者在错灯下走错方向，裴九娘用船头灯和口述路线纠正；曹肃让军士把错误写入值房，而不是把人赶走。
  6. 人流恢复后，顾与曹在门轴旁短暂对视，没有再交手；曹留下签名，顾公开说出自己曾是边军押运伍长。
  7. 门开只是阶段变化，水继续逼近第三仓；众人立刻把引导线改成转运线，动作不以庆功收尾。
- **选择与代价**：顾放弃个人指挥权，接受自己只是一个熟悉退路的人；曹肃、高问、梁成武各自留下签名，旧同袍的互救保留，盲从结束。
- **对白节点**：曹：“你还记得怎么排阵？”顾：“记得。今天排的是让人出去，不是让人听话。”高问：“那就把这句话写进责任栏。”
- **退出状态**：军伍能力被公共规则吸收；顾不复职、不回军中，旧身份从秘密变成可追问的事实。
- **连续性**：E36 不再使用打斗解决问题；旧军牌、旧军令缺页、AX-10 的记录和 AX-12 的公开身份共同回收。

## 7. 动作场交付检查

正式逐场剧本写入本动作骨架时，每场必须补齐：

`objective / obstacle / entry_state / tactic / turn / choice / changed_state / causes_next / relationship_delta / continuity_refs`

并逐项确认：

- 动作是否发生在已存在的 LOC 地点和当时的天气、材质、职业流程中；
- 顾行舟的动作是否由边军护送、前镖师和酒肆守门经验共同解释，而非临时获得新武功；
- 对手是否有现实目标，是否能在动作中改变策略；
- 打斗是否让一项证据、关系、路线、收入、身份或身体状态发生不可逆变化；
- 是否保留普通人的撤离、接力、记录和拒绝英雄化的空间；
- E01 与 E36 是否保持“动作克制、记录优先”的首尾呼应；
- 不写镜头、镜位、剪辑或生成提示，把这些选择交给 Director 与 Episode Gate。
