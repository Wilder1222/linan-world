## 尚需真实生成与人工选择的 Gate

以下是刻意保留给人工的生成期决策，不是文档或提示词缺失：

1. 运行 10 个 V2 风格校准任务，分别验证城市白日、金色人情时刻、手工半透材料、雨夜、灯火长廊、春台后台、公共节庆、水城全景与风纱情绪镜头，并选择项目生成候选。
2. 先逐人运行 12 条 `ID-001` 核心母版提示词，并由用户选择项目生成的身份候选；被选中的候选才可作为 Image Prompt 连续性来源。
3. 用户回传并记录该项目母版图后，才解除对应 `HERO-001`、三视图、表情、妆发、服装、动作、道具和剧情资产的身份 Gate。
4. 通过 V2 QA 后，将实际批准的 Style Reference 记录到 `production/assets/style/v2/`，并写入使用日志。
5. 按 catalog 的 `execution_status` 执行：所有 `BLOCKED` 记录必须等对应的核心母版、Season Gate 或 Episode Gate，不能被误当成可交付成片。
6. 选定的源图通过身份、城市、服装、无文字和连续性审查后，才进入 7680 像素交付链路；不得标为原生 8K。
