## P2：Season / 悬疑与短剧节奏

Character Foundation 锁定后再开始，不提前把 U/BG 写成主线角色。

### 1. 36 集因果与悬疑

- 每集采用“冷开场 → 四段因果推进 → 情绪尾钩”。
- 每集至少有：一个城市证据、一个关系选择、一个职业生活动作。
- 翻转必须经过“播种 → 误读 → 复核 → 重义”，不能靠新信息硬转。
- 每集结尾钩子必须同时回答：观众刚确认了什么、下一集必须追什么、哪段关系因此更难处理。

### 2. AI 短剧单集规格

- 正篇微短章默认 **2–3 分钟**；单集 18 章约 36–54 分钟的长集母版。
- 单章结构：0–10 秒冷钩子；10–45 秒目标与阻力；45–100 秒证据/关系动作；100–150 秒选择与代价；最后 10–20 秒尾钩。
- 每章只允许一个首要 POV、一个首要叙事功能、一个状态变化；生活活动必须推动关系或线索。
- 尾钩类型轮换：物证出现、人物误判、关系越界、制度反应、生活异常、选择倒计时。

### 3. 宋代生活与现代情绪入口

- 活动库优先使用夜市、茶坊、瓦舍、游湖、灯会、相扑、船运、书坊、家庭饮食与职业劳动。
- 每个活动必须填写：人物目标、现场阻力、关系变化、线索/生活变化、选择、状态变化、结束按钮、连续性成本。
- 现代观众的情绪入口可以是边界、照护、职业理想、信息失真、迁徙、亲密关系和选择权，但不出现现代网络词或现代制度解释。

### 4. 幽默使用边界

- 幽默只给有相应身份、职业和关系权限的人；优先冷笑话、错位反问、物件笑点、黑色幽默和“抢先一步”。
- 热梗只能做宋代语境转译；必须标注说话者意图、潜台词、反应顺序和笑意收回。
- 幽默必须改变距离、误解、线索或选择；不得消解死亡、创伤、洪灾与制度代价。

## P3：逐集与 AIGC 生产

固定流水线：

`Narrative Canon → Character State → Relationship State → Scene Goal → Emotion/Action → Dialogue → Blocking → Storyboard → AIGC → Continuity QA → Story QA`

每个生产单元必须能回溯到稳定 ID、关系 ID、地点 ID、道具 ID、已知信息和服装/伤病状态。上一层未锁定，下一层不进入正式生成。

## Gate 依赖与禁止事项

- 不在 Character Foundation 前锁定 Season。
- 不在 Episode Gate 前把 U 槽位写成唯一故事身份。
- 不把 BG 原型当作“群众装饰”；每次使用都要绑定地点、时段、劳动状态并可追溯。
- 不用一次性和解、完美正确或突然获得能力解决冲突。
- 不把“完成文件数”当作 Gate 通过；必须同时满足机器校验、人工审读和因果回收。

本轮只以 P1 Character Foundation 收口为完成：所有 P1 阶段校验通过、人工审读清单完成、Gate 证书明确锁定或明确列出阻断项。Season、648 微章正文、AIGC 成片属于下一轮，不在本轮用草稿冒充完成。
