# 制度五：Y0 危机因果链

| 事件 ID | 可见事件 | 直接机制 | 牵连系统 |
|---|---|---|---|
| EVT-Y0-001 | 白芷与香药价格异常 | 外路受阻与提前收购 | 药、香、街市 |
| EVT-Y0-002 | 三仓调拨延迟 | 账面集中与路线改写 | 粮、水、官署 |
| EVT-Y0-003 | 香箱出现不合时令的粮尘 | 掺运或仓储转移 | 香、粮、商贸 |
| EVT-Y0-004 | 瓦舍出现两种相反说法 | 版本被截取与改唱 | 曲、客、官署 |
| EVT-Y0-005 | 旧渠与桥闸通行异常 | 淤积、私堤和改图 | 水、图、城务 |
| EVT-Y0-006 | 青鹞吃水变深 | 装载变化与潮向异常 | 水、船、粮 |
| EVT-Y0-007 | 城南病例与水质恶化同步 | 排污回流与药缺 | 水、医、安置 |
| EVT-Y0-008 | 非常令收紧横向传递 | 只保留纵向汇总 | 信息、治安、隐私 |
| EVT-Y0-009 | 三仓粮火造成真实损失 | 集中储备与人为纵火 | 粮、火、救济 |
| EVT-Y0-010 | 强降雨叠加淤渠形成洪灾 | 延迟分洪与错误灯号 | 全系统 |

每个事件都必须在人物行动中留下时间、路线、物证或账目；不得用“幕后黑手万能”替代因果链。
