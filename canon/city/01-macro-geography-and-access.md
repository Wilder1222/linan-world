# 宏观地理与出入规则

## 1. 通行层级

城内巷道由坊巷、桥、渠、御街和水面组成；城门是行政和军伍控制点，桥闸是水路和人流控制点，码头是货物与外来人口控制点。普通人可以在白昼自由穿行主要商业轴，夜间需受更鼓、桥门和行业收摊习惯影响。

## 2. 六类访问权限

| 权限 | 常态 | 非常令下 |
|---|---|---|
| 居民通行 | 居住坊巷与商业区 | 需说明目的，不能任意跨水渠 |
| 商货通行 | 持货契、封签、船牌 | 加查重量、来源和目的地 |
| 医者通行 | 凭医籍或医棚名册 | 可优先通行但必须登记 |
| 递夫通行 | 凭递铺印记 | 只传递已验封件 |
| 军伍通行 | 依殿前司军令 | 不得私自征用民船 |
| 春信节点 | 可观察、记录、转递 | 无裁决权，必须标来源和时刻 |

## 3. 地理叙事规则

路线必须能解释人物为什么选择步行、船行、绕路或等待。任何捷径都要付出代价：失去隐私、错过时辰、暴露身份、增加潮汐风险或留下可追查痕迹。
