# 《临安春信》临安城市图谱 Canon

## 1. 城市骨架

临安由皇城与官署核心、御街商业轴、西湖西北文化游赏圈、鹤鸣巷与香药街、钱塘码头与船坊、城南水渠与安置区、外城门和城外三仓组成。城市繁华依赖水路、桥梁、井、仓、船、脚夫、茶坊、客舍和基层文书的共同运转。

## 2. 相对方向

| 地点 | 相对位置 | 主要连接 |
|---|---|---|
| 皇城/临安府 | 城中偏南 | 御街、城门、官署 |
| 御街与夜市 | 城中南北轴 | 鹤鸣巷、春台、酒楼 |
| 鹤鸣巷 | 御街东侧偏北 | 香药街、馄饨铺、桥渠 |
| 西湖/西泠 | 城西北 | 画舫、书画、茶坊 |
| 钱塘码头 | 城东南水路出口 | 青鹞、船坊、外港 |
| 城南水渠 | 城南低洼区 | 安置区、三仓、短堤 |
| 三仓 | 城南外缘高地与水路之间 | 汇川行、仓场、军粮线 |
| 外城门 | 城墙各出入口 | 北归社、客舍、官道 |

## 3. 出行硬规则

正常天气不得出现无解释的跨区瞬移；雨季、潮汐、封锁和查验都会增加时间。水路快于步行但受潮向、桥闸和泊位影响；官署与民间不得通过一句“有令”绕过签押和门禁。
