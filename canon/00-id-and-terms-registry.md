## 2. 唯一术语

- **微短章**：可独立发布的 120–180 秒正篇单元，正式编号为 `S1-E##-M##`。
- **母集**：约 45 分钟的长剧单集，由 18 个微短章组成。
- **篇**：六集组成的季内叙事单元，共六篇。
- **春信**：分布式城市观察、核验、传递和纠错方法，不是组织或门派。
- **疑报**：单一节点的带来源异常记录，不等于结论。
- **合报**：至少两条独立路径相互印证并区分事实、推断的记录。
- **无春**：粮、水、药、船、人五个系统中至少三个持续异常、相互放大且横向渠道受阻的最高预警；五类信道用于提供异质证据，不要求五类同时失灵。
- **公信案**：可公开核验、涉及公共生活的城市记录案件。
- **私情簿**：保存来源者身份、创伤、债务和保护信息的分级档案。
- **非常令**：有时限、有副署、有公开依据、可事后审查的危机行政命令。
- **S1**：第一季编号，不表示真实历史年号。
- **C0–C4**：正史层级；C0 为顶层事实，C1 为专项 Canon，C2 为扩展生活，C3 为外传，C4 为非正史实验。

## 3. 时间锚点

`PRE-Y13 → Y-13 → Y0-OPEN → ARC1-END → ARC2-END → ARC3-END → ARC4-END → ARC5-END → ARC6-END → ENDING → Y+1`。时间事实不得使用未登记的相对跳跃替代绝对锚点。
