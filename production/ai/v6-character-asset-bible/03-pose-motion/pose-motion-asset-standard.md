# 姿态与动作资产生产规范

基础姿态：standing_neutral / standing_alert / standing_tired / sitting_work / sitting_rest / walking_normal / walking_hurry / turning / kneeling / leaning。

情绪姿态：intimacy / hesitation / anger_controlled / anger_break / grief_silent / fear_hidden / relief / guilt / determination。

关系姿态：mother_daughter / lover_distance / lover_closeness / friend_trust / confrontation / reconciliation / farewell。

一个镜头优先只安排：1个主要身体动作 + 1个视线变化 + 1个情绪变化。复杂动作拆镜头。

每个动作都记录三层：L1身体动作、L2人物意图、L3关系意义。例：沈蘅把灯往里挪一寸=L1推灯；L2接受部分照顾；L3拒绝被替自己决定全部生活。
