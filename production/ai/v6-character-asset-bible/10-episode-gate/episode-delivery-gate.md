# 每集交付Gate

## A Character State Sheet
本集出场人物、开始状态、结束状态、变化原因。

## B Emotion & Action Sheet
每场主情绪、副情绪、动作、微表情、呼吸、视线。

## C Relationship Delta Sheet
信任、冲突、亲密、边界、新增关系事件。

## D Continuity Sheet
发型、服装、饰品、道具、伤口、时间、天气、知识状态。

## E QA
人物一致性 / 表情连续性 / 动作逻辑 / 行为逻辑 / 关系连续性 / 服装连续性 / 道具连续性 / 镜头表演 / AIGC稳定性 / 故事逻辑，各100分，最低90分。

其中“镜头表演 / AIGC 稳定性”必须额外核验 V2：城市是否可使用且非泛古镇、光源是否可解释、材质是否可区分、华丽度是否服从职业/场合、身份技术资产是否被风雾/首饰遮蔽，以及是否出现仙侠、额饰、露肤舞娘结构、现代物或文字/水印。
