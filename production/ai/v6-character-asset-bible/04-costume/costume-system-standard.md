# 服装资产系统

跨角色的可见构造语法、材质层次、精工预算与三位首轮验证角色由 [V2 层叠精工服装构造标准](../../../style/v2-costume-construction-standard.md) 管理。本文件保留资产编号与连续性要求；两者发生细节冲突时，以 V2 服装构造标准为表现层权威、以 Character Foundation 为人物事实权威。

每个角色不是一套衣服，而是：C01日常、C02工作、C03社交、C04正式、C05夜间、C06雨天、C07冬季、C08受伤、C09连续劳作、C10剧情特殊状态。

每套服装记录：颜色、材质、纹样、层次、袖型、腰线、鞋、发饰、首饰、使用痕迹、污渍、破损、天气适配、社会阶层、**华丽度等级、饰物预算、V2 光线槽位、主要/次要材质反应**。

硬规则：服装必须同时体现身份、职业、经济状况、季节、剧情阶段，不能所有人穿成同一种古风模特。

## V2 华丽度与饰物预算

| 服装状态 | 建议华丽度 | 饰物上限 | 材质重点 |
|---|---:|---|---|
| C01 日常 / C02 工作 / C09 连续劳作 | 1–3/5 | 一处功能性发饰、佩饰或耳饰 | 使用痕迹、织纹、袖口、腰封、耐候性 |
| C03 社交 / C04 正式 | 3–4/5 | 一个主饰物系统 | 暗纹、锦缘、层次和低饱和珠宝色 |
| C05 夜间 / C06 雨天 / C07 冬季 | 由场景决定 | 不因夜/雨自动加首饰 | 灯光、油纸、湿边、保暖层与收束发型 |
| 春台演出、节庆、婚宴、公开仪式 | 4–5/5 | 一主头饰 + 一组耳/颈饰 | 石榴/墨蓝/旧金的受控强调，丝织物与铜/玉局部反射 |
| C08 受伤 / 特殊危机 | 下调 | 只保留连续性所需饰物 | 污渍、收束、缺失/卸下的饰物必须可追溯 |

禁止用露肩露腰、额前垂饰、皇冠式发冠、链甲胸饰、手镯堆叠或异域舞娘结构表达“高级”。
