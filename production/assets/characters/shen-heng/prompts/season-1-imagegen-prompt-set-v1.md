# 沈蘅第一季 ImageGen 提示词合同 V1

## 生成模式

- 工具：Codex 内置 ImageGen。
- 身份依据：三张用户肖像 + `ID-001-neutral-identity-master-v2`。
- 每种资产单独生成一张图；人物图限定单人，不借用其他角色面孔。
