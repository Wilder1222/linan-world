# VIS-LW-V2｜场景构图与世界空间标准

> 状态：`ACTIVE-PRODUCTION-AUTHORITY`
> 适用：地点 Master、地点季节状态、城市建立镜头、风格校准；叙事分镜在不覆盖已锁定镜头轴与调度的前提下引用。
> 目标：把“繁华、可居住、有纵深的临安”落实为可选择、可追溯的空间构图，而不是把某一幅参考图的桥、水道或光线硬编码为全城默认。

## 1. 职责与编译顺序

每条场景提示词遵循以下层次：

```text
Canon 地点事实 → 已声明的季节/剧情状态 → Scene Composition Profile → V2 光线与材质路线 → Midjourney 参数
```

- **Canon 地点事实**拥有建筑、入口、出口、工作面、库存、连接路线与可见职业动作；构图档案不得新增水道、桥、门或地标。
- **地点状态**只改变已声明的天气、占用、门禁、货物、损伤和工作节奏；它不得重排稳定地理。
- **构图档案**拥有观察高度、前中后景的注意力顺序、道具密度和可读动线；它不拥有剧情、人物身份或具体镜头焦段。
- **V2 路线**拥有代表性风格、色彩处理、光源类型和材质响应；暖色仍必须有日光、纸灯、油灯、烛火、炉火或反射来源。

## 2. 共同的场景可读性规则

每个非技术地点图应同时给出：

1. 一组靠近镜头、实际可使用的物件或构件，承担前景尺度；
2. 一项中景职业动作、服务动作或通行行为，承担城市仍在运行的证据；
3. 一条进入远处的路线、建筑层级、水陆连接或公共功能锚点，承担空间纵深；
4. 由用途分组的道具，而不是无差别堆叠的杂物；
5. 与该地点材料、时段和工作方式相符的磨损、反光与天气影响。

道具的默认可见预算是：一个近景功能组、一个中景工作组、一个远景规模锚点。需要更多信息时，先增加功能关系和动线，再增加名词数量。

## 3. 可选构图档案

构图档案在 `v2-world-asset-visual-registry.json` 中以 `composition_profile_id` 绑定。它们是可复用的观察逻辑，不是所有场景都要出现的固定物件。

| 档案 | 绑定地点/用途 | 可见逻辑 |
|---|---|---|
| `SCN-LANE-COMMERCE` | 鹤鸣巷、香药街 | 近景交易/家用物 → 门槛或转角 → 屋檐与通行巷道 |
| `SCN-WORKSHOP-THRESHOLD` | 香铺、书坊画铺 | 工具/材料 → 工作台与服务口 → 后场或第二工作面 |
| `SCN-CIVIC-AVENUE` | 御街 | 服务摊/车辆 → 人车交叉 → 公共街道与屋檐层级 |
| `SCN-LANTERN-MARKET` | 御街夜市 | 食物/灯笼/篷布 → 服务路径 → 灯火与店铺后退 |
| `SCN-PERFORMANCE-SERVICE` | 春台瓦舍 | 幕边/乐器/修补 → 演员与服务流 → 舞台和后台入口 |
| `SCN-WATERFRONT-HOSPITALITY` | 西湖画舫 | 船篷/绳栏/茶器 → 登船或服务动作 → 靠泊与湖岸 |
| `SCN-HOSPITALITY-PASSAGE` | 停云酒肆 | 茶器/桌缘 → 侍应与座位 → 院落、湖岸或街口 |
| `SCN-WATERFRONT-LOGISTICS` | 钱塘码头、船坊水上茶摊 | 货物/绳索/工具 → 水陆装卸 → 船、泊位与维修层级 |
| `SCN-VESSEL-DECK` | 青鹞 | 船栏/舱缘/货包 → 船员操作 → 甲板、舱位与水面关系 |
| `SCN-CIVIC-OPERATIONS` | 城务司、三仓 | 文书/量具/消防物 → 队列或工作道 → 库位、架位与受控入口 |

| `SCN-CARE-ROUTE` | 小济堂、城南安置区 | 照护/给水/配餐物 → 服务路径 → 棚下、洗点或救助区 |

| `SCN-WATER-CAPITAL-ESTABLISHING` | 三张城市建立镜头 | 水、桥、市场与建筑尺度在宽幅画面中的层级关系 |

## 4. 街级水岸市集的使用边界

`SCN-STREET-LEVEL-WATER-MARKET` 吸收的是“近景生活密度 → 中景通行关口 → 远景城市规模”的构图机制。它适合风格校准、经过地点卡确认的水岸镜头或后续明确绑定的分镜。

- 桥、桥洞、临水平台、远处公共建筑、船只、莲叶、牲畜和特定摊货都不是默认项；只有 Canon 或分镜声明后才可进入具体地点图。
- 人眼高度、自然广角和深环境焦点是街级空间研究的可选镜头设定；人物关系图与情绪剧照仍按各自的镜头任务处理。
- 布篷、篮筐、陶罐、货包、低桌等只在能说明准备、服务、储存、搬运或通行时出现。它们用于形成有组织的生活密度，而不是旅游古镇装饰。

## 5. 生成与审查

1. 先运行 `CALIBRATION:DAY-CANAL`，确认水岸市集档案与 `V2-Day` 同时成立。
2. 地点 Master 与六篇状态使用其登记的档案；生成图须保留地点卡定义的入口、工作面和通行关系。
3. 分镜由已锁定的镜头、动作轴和物理光源优先；构图档案只可补充未被分镜指定的空间层次。
4. 选择候选时，按 `v2-visual-qa.md` 复核前中后景、动线、道具分组、材质和光源，再记录实际候选与人工选择理由。

本标准不声称单次生成能保证地图准确性、连续性或历史考据；这些结论只能来自对应地点的 Canon、分镜和人工审查证据。
