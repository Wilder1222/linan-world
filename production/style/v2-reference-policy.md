# VIS-LW-V2｜参考图、身份连续性与外传政策

## 1. 默认规则

用户上传、聊天附件和 `raw/` 下的图片只可作为本地设计期观察证据。它们不自动上传到 Midjourney、第三方服务、公开仓库或任何外部链接。

每张参考图在被用于外部生成前，必须人工记录：来源、权利/授权、用途、是否允许外传、是否只允许风格观察、是否允许身份连续性参考，以及失效日期或撤销条件。

## 2. 当前项目的分级

| 来源 | 当前用途 | 可自动外传 | 可作为 V8.2 Image Prompt |
|---|---|---:|---:|
| 用户上传与聊天附件 | 妆容、服装、光线、镜头语言的设计期分析 | 否 | 否，除非用户明确确认权利与用途 |
| `raw/` 原始图 | 本地候选与审美对照 | 否 | 否，除非完成相同确认 |
| `production/assets/` 已选项目生成资产 | 连续性复审和内部生产候选 | 否，默认仍需检查 | 可以，在获得角色/资产负责人批准后 |
| 通过 V2 QA 的项目风格候选 | 路线一致性 | 否，默认仍需检查 | 只在人工选择并记录实际值后 |

## 3. 柳十四参考图的使用边界

`raw/liushisi/` 中的图片可用于分析柳十四的风格方向：清透淡妆、真实肤面微纹理、水雾感、发丝反光、春台层叠织物和克制首饰。它们不能覆盖人物 Canon：柳十四仍是 25 岁、春台瓦舍歌伎与曲作者，固定识别点仍是细长明亮的眼睛、右嘴角先起的近笑、职业性的开阔体态与台下收束感。

参考图中的过量额饰、异域舞娘剪裁、露腰露肩、皇冠堆饰、奇幻粒子、灰绿眼睛和非宋代宫廷化结构只能作为反例，不进入正式资产。

## 4. 全局电影化新宋韵参考方向

当前聊天中提供的夜宴/灯火长廊及两张白日参考图，已作为 **VIS-LW-V2 的设计期视觉方向** 被文字化写入 `v2-urban-splendor-song-style-package.md`：

- 夜景提取：暖色纸灯、烛火、暗朱木构、象牙帷幔、蓝灰外界、连续纵深和只围绕真实亮点出现的轻微高光晕染。
- 白日提取：低角度午后日光下的人情时刻，以及穿过薄绢/布料的劳动场景；丝绸、皮肤、茶盏、木器和城市手工活动共享同一个物理光场。
- 只提取镜头、灯光、材质、空间和华丽度控制，不复制具体人物容貌、服装图案、画面人物关系或任意可识别来源。

这些图片仍只可本地观察，不能因为已写入风格合同就自动作为 Midjourney Image Prompt、Style Reference 或外部上传附件。

## 4.1 本轮世界参考图的编译边界

本轮新增的两组十张世界参考图已被拆解为[世界视觉参考图拆解与提示词方向](v2-world-reference-atoms.md)。该文档只记录可迁移的光线、材料、镜头、服装层次、城市密度和华丽度机制，不记录原图路径、人物身份、可识别脸部、具体招牌文字或精确地理。

其中“春台近景妆发华彩”和“节庆表演服装”只为柳十四等表演/社交状态提供材料与配饰层次；“水城建立镜头”只提供水陆贸易、屋顶密度和空气透视的方向，不能反向成为临安历史地理或建筑考据。

## 5. 沈蘅身份连续性

沈蘅的当前 Canon 年龄为 **20 岁**。任何新生成或重建资产必须以 `characters/central/chr-l1-01-shen-heng.md` 为年龄和身份权威；既有图像只能作为待复审的连续性候选，不能以旧图反向修改年龄、脸部锚点或职业。

若需要 V8.2 Image Prompt 辅助连续性，应先选择一张通过 V2 QA 的项目生成身份图，再记录它的资产路径、哈希、角色用途、获批日期和实际生成会话。原始肖像、聊天附件和外部示意图都不能被默认使用。

## 6. Style Reference 使用规则

三条 V2 路线先靠完整文本合同运行。只有当 V2 校准候选经人工选定并有实际可用的 Style Code 或 URL 时，才可把它加入相应路线的生成会话；每次使用都记录路线、实际值、强度、生成日期和 QA 结论。禁止把虚构链接、通用别名或跨路线参考写进可复制提示词。

## 7. 可审计记录

每次实际引用应写入资产记录：

- `prompt_id` 与 catalog 版本；
- 参考来源与 SHA-256；
- 权利与外传确认；
- Image Prompt 或 Style Reference 的实际值；
- 路线、强度、人工选图原因与复审结果；
- 任何撤销、重建或身份变化的影响范围。
