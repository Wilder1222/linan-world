# 《临安春信》V2 视觉风格权威

`VIS-LW-V2` 是项目当前唯一的视觉合同：**都市华美宋韵 × 电影化新宋韵**。它以“富庶都市基底 + 日常精工穿着 + 春台/节庆华彩升级”构成；不以玄幻符号、宫廷堆饰或裸露结构制造“高级感”。

- [V2 服装构造标准](v2-costume-construction-standard.md)：所有人物的层次、材质、精工预算、职业适配与 C01–C10 服装升级规则。
- [参考图政策](v2-reference-policy.md)：用户参考仅作设计期证据，禁止自动外传或未授权复用。

## 三条职责明确的路线

| 路线 | 使用范围 | 华丽度 | 不能变成 |
|---|---|---:|---|
| `V2-Day` | 人物母版、城市白日、职业劳动、证据 | 1–3 | 灰绿滤镜、空古镇、影楼白墙 |
| `V2-Night-Wet` | 夜市、灯火长廊、雨夜、码头、低照度工作与封水状态 | 2–3 | 霓虹、仙雾、灾难奇观 |
| `V2-Stage-Festival` | 春台演出、桂花夜市、节庆与雅集 | 3–5 | 宫廷、异域舞娘、满身珠宝或奇幻公主 |

技术性身份、三视图、表情、妆发、服装结构和道具资产固定走 `V2-Day` 的清晰技术通道；它们不承担氛围海报任务。

当前不存在默认全局风格图片。先用 V2 校准提示词生成候选并经人工 QA 选择；在选择前，所有可复制提示词都通过语义约束保证一致性，而不嵌入无效链接或占位符。
