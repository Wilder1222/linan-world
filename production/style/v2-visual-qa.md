# VIS-LW-V2｜视觉校准与验收表

每次建立新的角色、地点或叙事资产前，先用 `production/midjourney/v2/` 的五张校准任务确认当前 Midjourney 8.2 会话能稳定落在 V2 三条路线。通过校准不等于已经锁定全局风格图；任何具体图仍须人工选择。

## A. 五张校准任务的共同判据

- 南宋临安必须是高密度、有人劳动、货物流动和水陆路线可读的城市。
- 人、纸、丝、油纸、漆木、竹、陶、铜、湿石和水的材质响应必须不同。
- 灯、窗、炉火、天光、水面反射都必须有实际来源；禁止无来源轮廓光和悬浮辉光。
- 全图无可读错误文字、水印、签名或商标。
- V2 的华丽由织纹、染色、叠穿、维护痕迹和受控反光表达，不能靠裸露、额饰、皇冠或宝石堆叠。
- 叙事性画面应有可读的前景、中景和远景：近处可由帷幔、窗棂、货架、灯笼或船篷轻框景，中景承担人物/劳动，远处沿真实建筑、路径、人流或灯火后退；技术资产除外。
- 白日图须根据用途二选一或混合使用“金色人情时刻”与“手工半透材料”母题：低角度日光、透光织物和工作动作均要有物理来源，不能成为过曝人像或空洞唯美布景。

## B. 人物验收

1. 年龄、职业、身份锚点和行为痕迹与人物档案一致。
2. 重要人物漂亮但各自可辨：不能出现同一张网红脸、娃娃眼或极尖 V 脸。
3. 皮肤清透健康而真实：有细微毛孔、绒毛、唇纹、自然眼睑和局部肤色变化；无塑料、蜡质、瓷肌或强磨皮。
4. 妆容轻薄，能增强气色但不改变身份；现代浓眼线、夸张假睫和重轮廓为失败。
5. 服装造型符合角色的华丽度预算；春台/节庆可更精致，劳动/证据/雨冬状态必须优先可用性。
6. 身份连续性只可由通过权利与用途审查的项目生成身份图作为 V8.2 Image Prompt 辅助；原始用户上传不自动送入外部生成。

## C. 地点与城市验收

1. 有水道、门槛、货物、人流和职业路径；不能只剩空屋檐或泛化古镇。
2. 每个地点的季节状态保留原有建筑、出入口、工作台、库存与通行关系，只改变 Canon 已声明的状态差异。
3. 夜雨有局部灯源、湿度和持续劳动，不能变成霓虹夜景或灾难奇观。
4. 春台与节庆有节目/市场/后台劳动链，不能变成皇宫宴会。
5. 灯火长廊、夜宴或社交夜景以纸灯、烛火、木构、象牙帷幔和克制蓝灰外界构成，灯光/散景/轻微晕光均须由真实亮点触发。

## D. 技术资产验收

- 一角度、一表情、一套服装、一项动作或一个物件只生成一个独立候选任务。
- 正面、左右三分之四、严格侧面、背面、表情、妆发、动作和道具在本地编排为版；不把拼板生成当成身份一致性的证据。
- 三视图和服装资产要露出完整轮廓与结构，背景简洁，镜头不做过度景深或装饰性运动。

## E. 交付门槛

1. 通过 Canon、身份、服装、风格、无文字和连续性审查。
2. 核对所用 V8.2 直接提示词与 `v2-asset-prompt-catalog.json` 中的 `prompt_id` 一致。
3. 记录被选候选、参考图授权、任何 Image Prompt/Style Reference 的实际值和复审结论。
4. 再进入项目 7680 像素交付流程；不得把生成模型的候选输出称作原生 8K。
